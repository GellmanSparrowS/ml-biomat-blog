# Read and search ML-Biomat

ML-Biomat provides Chinese and English tutorials on scientific Python, machine learning,
biomaterials, multiscale modeling and experimental data analysis.

## Find content
- Start with https://ml-biomat.com/llms.txt for the current catalog.
- Search title, description, tags and category in https://ml-biomat.com/search.json.
- Use https://ml-biomat.com/agent-index.json to map canonical page URLs to Markdown URLs.
- Fetch the listed Markdown URL to read the complete text without site navigation or advertisements.
- Browse https://ml-biomat.com/categories/ or https://ml-biomat.com/categories/en/.

## Reading
The index gives each page's language; Chinese and English pages have separate URLs.
Preserve formulas, units, citations and the distinction between teaching examples and experimental data.
Cite the canonical HTML URL supplied with the Markdown. Interactive experiments remain on that page.
Follow source attribution and license notices for content reuse.

## Browser tools
Browsers implementing WebMCP can expose search_tutorials, list_tutorial_topics and read_page.
These tools only read public content and require no registration or credentials.
