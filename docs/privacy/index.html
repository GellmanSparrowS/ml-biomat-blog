隐私政策

更新日期：2026年10月28日

1. 关于本网站

ML-Biomat（ml-biomat.com）是由复旦大学杨云浩维护的个人学术网站。

2. 第三方服务

阅读本网站无需注册账号。页面集成的第三方服务可能处理访问相关信息：

  • Google AdSense：通过 Cookie 等技术展示广告，可能处理 IP 地址、浏览器类型和浏览行为，并根据广告设置提供个性化广告。
  • Giscus 评论：使用 GitHub 进行账号认证，相关 GitHub 个人资料由 GitHub 处理。

3. Cookie 与本地偏好

Google AdSense 可能使用 Cookie，根据读者此前对本网站或其他网站的访问展示广告。可以在 Google 广告设置中管理个性化广告。

网站使用浏览器本地存储保存亮色或暗色主题偏好，便于在切换页面后保留所选主题。

4. 数据使用

网站运营者不出售或交易读者的个人信息。第三方服务所处理的数据受其各自隐私政策约束。

5. 管理偏好

可以在浏览器设置中限制或清除 Cookie 及网站本地数据，也可以通过 Google 广告设置调整个性化广告偏好。清除网站本地数据后，主题将恢复默认设置。

6. 联系方式

有关隐私的问题，请联系 Gellmansparrow@outlook.com。
