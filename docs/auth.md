# ML-Biomat auth.md

## Public access
ML-Biomat publishes bilingual research tutorials, articles and software documentation.
Reading these public resources requires no account, registration, API key or bearer token.

## Resources
- Tutorial catalog: https://ml-biomat.com/categories/
- Search index: https://ml-biomat.com/search.json
- Agent reading guide: https://ml-biomat.com/llms.txt
- Markdown page index: https://ml-biomat.com/agent-index.json
- FiberNet documentation: https://ml-biomat.com/fibernet/

## Registration and credentials
Public reading has no agent registration endpoint or OAuth authorization server.
Retrieve public resources without sending credentials.

## Content reuse
Follow the attribution and license notices attached to each article, image,
code example and downloadable package.
