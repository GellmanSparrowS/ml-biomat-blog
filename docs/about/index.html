研究内容

生物材料体系与跨尺度结构

从分子、纤维到网络及宏观材料，关注组成、层级结构和相互作用如何影响材料的力学行为与功能。研究涉及结构蛋白、纤维网络与柔性材料等体系。

物理人工智能与多尺度模拟

将物理信息与机器学习方法结合，通过多尺度模拟、实验验证和优化设计，建立结构与性能之间的联系，服务于材料体系与结构的理性设计。

SELECTED WORK

代表研究与项目

01 可制造设计

可制造纤维网络的智能设计

围绕纤维连续路径与拓扑约束，开展可制造纤维网络的 AI 引导设计研究。将拓扑生成、有限元分析、图神经网络与强化学习串联，并通过三维打印样品验证设计，实现从结构方案到物理材料的贯通。

REFINe · Nature Communications · 2026

阅读论文 ↗
研究问题、方法与成果+
研究问题
如何在设计阶段同时考虑纤维网络的力学表现与连续制造要求，使数字拓扑能够转化为可编织、可打印的结构？
研究方法
构建 REFINe 框架，以 TOPNet 算法保持纤维路径的连续性；结合自动化有限元分析、物理启发的图神经网络和强化学习，完成力学响应预测与拓扑优化，再将平面网络映射到曲面。
成果与验证
论文中的优化结构相较初始设计实现约 50% 的强度提升与约 20% 的质量降低，并通过 SLA 与 FDM 三维打印样品开展实验验证。

02 物理引导学习

无序纤维网络的形变与力学预测

参与物理引导图神经网络研究，将网络连接关系与物理信息融入学习过程，预测无序纤维材料的形变及应力–应变响应，为复杂网络的快速力学评估与结构设计提供计算方法。

GNMP · Nano Letters · 2026

阅读论文 ↗
研究问题、方法与成果+
研究问题
无序纤维网络的稀疏连接与非均匀形变增加了力学预测的难度。如何利用网络结构信息，快速预测节点形变与整体应力–应变响应？
研究方法
将图注意力消息传递、多尺度物理嵌入与键长引导的调度策略结合，构建 GNMP 预测方法，描述二维半柔性网络中的非仿射重排。
成果与验证
研究将预测结果与分子动力学模拟进行比较，并通过三维打印网络实验考察形变模式与结构描述量，为纤维网络的快速力学评估提供方法。

03 开源工具

FiberNet / FiberScope

面向纤维网络设计、模拟与智能优化的开源项目。FiberNet 提供 Python 计算工具，FiberScope 提供交互式研究入口，让结构生成、力学分析与逆向设计更便于使用和复现。

GitHub 源码 ↗ 体验 FiberScope ↗ 项目介绍 →
工具流程与使用入口+
使用问题
把分散的结构生成、模拟、分析与设计步骤接入同一套工作流，便于在 Python 中批量研究，也便于通过图形界面探索结构。
工具方法
FiberNet 提供二维与三维网络生成、梁框架 FEM、结构描述量分析和目标曲线搜索等接口；FiberScope 提供结构编辑、轨迹查看与几何导出入口。
示例与输出
公开示例覆盖网络生成、模拟结果保存与重载、结构特征提取，以及平面和曲面连续路径的构建；配套源码与方法说明记录各步骤的参数和输出。
