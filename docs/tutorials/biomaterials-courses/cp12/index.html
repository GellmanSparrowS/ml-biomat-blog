长链怎样移动和回弹：柔性高分子的动力学

同一块软材料，缓慢拉动时会流动，快速拉动时却明显回弹。沿着加载、等待和释放的过程，理解应力如何消失；再把宏观松弛连接到链段运动、流体耦合和缠结约束，用可调节的振荡实验读懂储能与损耗。

软硬为什么取决于观察时间

一团聚合物熔体可以缓慢摊开，也可以在短时间拉伸后回缩；压敏胶需要在接触时流进表面细节，又需要在揭起时承受载荷。这些行为不是简单的“既像固体又像液体”就能解释。真正的问题是：外部改变形状有多快，分子需要多久才能重新安排，以及观察在重新安排完成之前还是之后进行。材料的组成相同，测量时间改变，测得的力学响应也可以明显不同。

柔性高分子由许多相连链段组成，局部链段能在热运动中改变位置和方向，但相邻链段不能独立离开。推动一个部分，会通过连接影响其余部分。溶剂或邻近链提供阻力，缠结又限制某些横向运动，于是局部小幅调整、整条链改变形状与链逃离原先邻居环境，分别需要不同时间。宏观应力记录的是许多这些运动共同留下的记忆。

先用平行板剪切建立清楚的测量。固定下板，上板沿水平方向移动，板间材料的顶层相对底层发生位移。剪切应变是这个位移与板间距的比值，描述形状变化程度；剪切应力是切向力除以受力面积，描述单位面积需要多大作用。把力和位移分别除以面积与厚度，才能在不同尺寸样品之间比较材料行为，而不是只比较仪器读数。

若材料是理想弹簧，应力只跟当前应变有关，撤去应力便回复；若是理想牛顿黏性元件，应力跟应变变化的速率有关，持续施力会持续变形。真实高分子在一定条件下同时表现可恢复与不可恢复部分，且两者随时间变化。这里的弹簧与黏性元件是描述关系的机械模型，不是说一条分子内部真的安装了金属弹簧或活塞。

实验还必须控制形变大小。小形变范围内，把输入应变加倍，输出应力也近似加倍，称为线性响应；不同时间施加的小扰动也可以相加。形变更大时，链取向、伸展、结构破坏或接触滑移可能改变响应，简单加倍关系就不再成立。线性流变是理解松弛的清楚起点，因为它尽量在不大幅改变结构的条件下读取材料已有的时间尺度。

温度与材料状态同样要说明。下面的链模型主要描述链段能够运动的柔性聚合物溶液或熔体。玻璃态中局部运动冻结、晶区充当额外约束、化学网络保留长期弹性时，响应还包含其他机制。同一聚合物名称并不指定它处于哪种状态；分子量、浓度、温度和是否交联，决定我们接下来采用哪个动力学图景。

让形变固定，看应力怎样消失

把材料迅速剪切到一个小应变，然后保持形状不动，测得的应力通常会随时间降低，这叫应力松弛。开始时链来不及调整，产生较大的应力；等待期间，链逐渐重排，维持同一形状所需的应力减小。另一种实验是突然施加一个恒定小应力，观察应变怎样继续增加，称为蠕变。两种实验分别固定不同的量，曲线不能在每个时刻简单互取倒数。

Maxwell在1867年讨论动力学与黏性时，引入弹性作用以特征时间逐渐松弛的思想。今天常用一个弹簧与一个黏性元件串联来表示最简单的Maxwell模型。串联意味着两部分承受相同应力，总应变是两部分应变之和。弹簧的形变由应力决定，黏性元件的形变速率由应力决定，把两种贡献相加，就得到一个同时含应力及其变化率的关系。

模型也给出蠕变：刚施加应力时，弹簧立即提供一个应变跳跃，随后黏性元件以恒定速率继续变形。撤去应力后，弹簧部分回复，黏性元件积累的形变留下。因此，一个Maxwell元件在足够长时间上表现为流体，即使在较短时间内可明显储存弹性能。若材料真正具有长期平衡弹性，还需加入能够永久承力的部分，不能强行让单一Maxwell模型解释全部情况。

这个模型的用途是把一个清楚的时间尺度与实验联系起来。它可以近似某个占主导的松弛过程，但真实长链通常拥有许多松弛时间。若实验的应力衰减呈现明显拖尾，或不同频率下的响应无法由同一参数组描述，应该增加与结构相符的松弛模式，而不是只反复调整一个时间常数。模型的复杂度应跟实验所能分辨的过程相匹配。

理想阶跃也需要实验判断。上板不可能在零时间内移动，若加载时间已经接近最快的松弛时间，一部分应力会在加载过程中消失。记录真实加载过程并检查仪器惯性、夹具滑移与样品边缘状态，才能把材料松弛与测量过程分开。一个漂亮的指数拟合并不能替代对输入形变的准确了解。

来回变形怎样分开储能与损耗

与突然加载相比，轻轻地来回剪切材料可以在稳定重复的状态下读取响应。让应变按正弦规律变化，意味着形变在正负之间平滑往复；角频率描述周期推进的快慢，每秒完整往复的次数乘2π就是角频率。在线性范围内，应力也以同样频率变化，但相位一般不同。把应力分解为与应变同步的部分，以及与应变速率同步的部分，就得到储能模量与损耗模量。

损耗模量大并不自动意味着每秒发热最大。每周期损失还依赖应变幅度平方，而每秒经历多少周期又取决于频率。比较减振性能时，需要同时指定幅度、频率和试样体积。把应变幅度从1%提高到2%，在线性条件仍成立时，每周期损失增加四倍；若更大幅度已经改变结构，便要测量完整非线性回线，而不再直接使用小振幅公式。

频率扫描因此是一种时间尺度扫描。慢频率给材料更多时间调整，快频率冻结较慢的模式，使它们在一个周期内主要表现为储能。模量随频率的变化不是材料在仪器里不断换一种化学组成，而是同一组内部自由度能否及时响应。把扫描结果与应力松弛实验对应起来，能够检验同一物理图景是否同时解释不同加载方式。

一条长链为什么有一整组松弛时间

把一根长绳稍微弄弯，只调整相邻一小段，就能消除一个很短的弯曲；若整根绳从一侧弯向另一侧，需要更多部分协调移动。柔性链也有不同空间尺度的形状变化，但它在热运动与阻力中不断涨落。局部模式通常较快，涉及很长链段的模式较慢。每一种模式不必对应一种新的化学键，而可以是同一组链段以不同协同方式移动。

在线性范围，把许多独立的Maxwell响应相加，就得到离散松弛谱。每个模式有自己的模量权重和松弛时间，快模式先消失，慢模式留下长尾。若时间分布连续，可以用积分表示；积分就是把许多很窄的小区间贡献不断相加。宏观应力同样可以看成过去每一次微小变形留下的响应之和，越早发生的变形，已经经历的松弛时间越长。

历史积分中的核函数是松弛模量，它告诉我们一次很小的应变增量经过等待后还能贡献多少应力。这里没有假设材料会有意识地记住过去；记忆来自尚未恢复的分子构象与约束。对一个始终处于线性范围的过程，把输入切成许多小段并相加，就能够预测应力。若材料老化、反应或被大形变改变结构，核函数可能不再只依赖时间差，简单的时间平移不变性就需要重新检查。

低速稳态黏度可以由松弛模量随时间的面积得到。一个较小但持续很久的模量贡献，也能显著增加这个面积。因此少量超长链有时会大幅改变流动阻力，而对短时间的初始模量影响不那么明显。分子量分布、长支链与暂态结合，都可能使长时间尾部变宽。仅用一个平均分子量解释全部流变曲线，容易漏掉这些权重不同的贡献。

从有限频率范围的数据反推松弛谱通常不是唯一的。若两组不同的模式在测量窗口内给出近似相同曲线，数据就没有充分区分它们。更宽的时间范围、蠕变与松弛的交叉检查，以及分子量和结构信息，可以限制可行解释。谱拟合的目的，是以足够少的参数概括可分辨的时间结构，并把它与分子机制联系起来，而不是把每个拟合峰都当成已确认的新运动。

这些模式既可以来自单条链，也可以来自多链环境。接下来先看没有显著拓扑约束时的链内协调运动，再看溶剂如何把不同部分耦合，最后进入链彼此不能穿过的缠结体系。每增加一种物理因素，改变的是阻力、可达运动或协同范围；保持这个顺序，就能理解模型之间为何给出不同的分子量标度。

Rouse模型：连接使局部运动彼此协调

Rouse在1953年建立盘曲高分子稀溶液的线性黏弹理论，把链分成许多足够长、端到端分布近似高斯的子链。每个粗粒化节点受到局部阻力与热噪声，相邻节点由代表构象熵的弹簧连接。这里的弹簧较长，代表一段包含许多化学键的柔性链，而不是一根共价键的伸缩。粗粒化保留需要研究的慢运动，把更快的局部细节收进有效参数。

最简单的Rouse近似忽略不同节点之间通过流体传递的远程动力学耦合，也不包含链不能互相穿过所造成的长时间缠结约束。因此每个节点的摩擦可以直接相加。整条链平移时，节点数增加，整体阻力增加，质心扩散变慢；形状恢复还需要连接协调，使最长松弛时间比单个节点时间增长得更快。把节点运动分解成正常模式，可以把复杂协同运动变成许多各自衰减的模式。

Rouse标度的一个直接结果，是链长加倍时，质心扩散系数约减半，最长内部松弛时间约增加四倍，前提是温度、节点摩擦和有效链段长度不变。真实化学聚合物改变分子量时，局部摩擦也可能随温度相对玻璃化位置变化，因此比较标度最好在相同状态下进行。分子链太短时，高斯子链与连续模式近似本身也需要检查。

Rouse模型最初面向稀溶液，但忽略流体远程耦合在一般稀溶液中并不充分；它在未缠结熔体或某些被屏蔽的尺度范围内常提供有用描述。这里的动力学屏蔽与静态排除体积屏蔽是不同问题。一个链在熔体中具有近似理想的尺寸统计，并不意味着它可以忽略所有邻链约束，也不意味着熔体在所有动力学尺度都等同于θ溶液。

模型还明确了线性理论的边界。高斯弹簧在数学上可以无限伸长，真实链的轮廓长度却有限。强流动把链拉得很长时，必须考虑有限伸展和非线性阻力或约束变化。用线性模型解释小形变松弛非常有用，把其弹簧一直拉到超出真实链长，则会失去分子意义。

Zimm模型：流体把链的不同部分连接起来

在稀溶液中，移动一个链段会扰动周围流体，这个流动又影响较远的链段。即使它们沿分子骨架并不相邻，仍可通过溶剂交换动量，形成流体动力学相互作用。把所有节点阻力简单相加，会遗漏这种协同运动。Zimm在1956年把这项耦合纳入珠簧链模型，解释稀溶液黏弹性、流动双折射等响应的松弛谱。

一个量级图景是把大尺度线团运动看成拖动一个尺度为R的流体区域。它的有效阻力随溶剂黏度与线团尺寸增长，热运动要让线团移动自身大小的距离，需要的时间因而与黏度乘尺寸三次方成正比。这个图景保留了随尺寸变化的趋势，具体系数取决于线团形状、尺寸定义及所采用的动力学近似，不能把线团直接当成边界完全相同的硬球。

在良溶剂中，线团尺寸随链段数约按0.588次方增长，因此Zimm最长时间约按链段数的1.764次方增长；在近似θ条件下，尺寸指数约为1/2，对应时间指数3/2。这些指数从相同尺寸三次方关系导出，并非每种聚合物都共享一个不变的数值。溶剂质量改变链的静态尺寸，流体耦合决定如何把这个尺寸转为动态时间，两项物理作用共同进入结果。

浓度增加后，许多链占据同一空间，流体运动受到集体环境影响，不同长度与时间范围的水动力耦合可以发生交叉。很短尺度上，链段仍可能感受到附近溶剂；在更大尺度上，简单稀溶液Zimm图景逐渐不适用。继续增加浓度和链长，又会进入缠结约束显著的范围。因此“溶液”不是一个足以指定模型的词，至少还需知道是否低于线团交叠浓度、所观察尺度以及溶剂环境。

实验可以通过散射关联函数、单链标记位移和频率响应来区分这些动力学。散射并不直接拍出每一条链，而是观察某个空间波长的浓度或构象关联如何随时间消失。大波长对应大尺度运动，小波长对应局部运动。若不同尺度的衰减不能用一个整体扩散时间解释，就说明内部模式正在发挥作用。这与流变测量中出现宽松弛谱，是对同一层次结构的不同观察。

把Rouse与Zimm放在一起，最重要的判断是阻力如何累积。Rouse把节点阻力看成局部可加，Zimm保留通过流体产生的集体耦合。两者都可以从热噪声、连接与阻力出发建立统计预测，但保留的相互作用不同。分子量标度的变化由此有了物理来源，也为理解更浓体系中的拓扑约束做好准备。

缠结如何让整链松弛变得很慢

在足够长链的浓溶液或熔体中，一条链周围充满其他链。它们没有在每个接触处形成永久化学键，却不能轻易彼此穿过。局部链段仍可移动，但若整条链想横向大幅改变位置，就必须与周围许多链协调。把这些拓扑约束的平均作用看成一根限制横向运动的虚拟管道，便得到管模型。管道不是实体孔壁，而是邻链约束随时间形成的有效描述。

de Gennes在1971年研究链在固定障碍中的运动，提出爬行图景：链主要沿自身曲折的通道移动，像从原有套管中逐渐抽出。Doi和Edwards在1978年的工作进一步把缠结链运动与浓聚合物体系的应力联系起来。链端进入新区域，原通道的记忆逐渐消失；完全更新所需时间，比未缠结链的形状恢复更强烈地随链长增长。

最简单的固定管标度给出终端时间随链长三次方增长，质心扩散系数随链长平方的倒数下降。链长加倍，终端时间约增加八倍，扩散约降为四分之一。真实熔体中，邻链也在动，管约束会释放；链端还会通过轮廓长度涨落更快地更新局部通道。这些机制使有限分子量区间的有效指数偏离最简单标度，实验常见的约3.4黏度指数也不应被当成所有体系的严格定律。

在局部运动已完成、整条链尚未逃离管道的中间时间范围，材料可以出现近似橡胶平台。平台模量反映有效缠结约束密度，终端时间则反映这些约束的记忆能保留多久。增加链长主要延长终端时间，不一定以相同比例增加已建立平台的高度。因此高分子量熔体可以黏度显著升高，而平台模量变化较小。黏度与模量的不同分子量依赖并不矛盾。

永久交联网络与缠结熔体在这里有清楚区别。永久网络保留长期连接，理想条件下有非零平衡剪切模量；线性链熔体的缠结约束最终可以松弛，足够长时间后仍能流动。长支链、环形分子、暂态结合或不同分子量混合会改变约束更新路径，不能只把同一个管逃逸时间换一个数值就涵盖所有结构。

在加工中，长终端时间使材料在快速流动时保留取向和应力，影响挤出胀大、拉伸稳定性与焊接界面的恢复。两块聚合物表面接触后，链需要穿过界面并建立跨界约束，单靠表面贴合不能立即恢复主体强度。把扩散、松弛和加工等待时间比较，就能把微观管道记忆与宏观成形质量联系起来。

温度怎样移动整个时间窗口

温度升高时，许多聚合物的局部链段运动变快，原本要等待很久才能完成的松弛进入较短时间窗口。因此升温与降低观察频率有时会产生相似效果：材料有更多机会在外部变化期间完成内部调整。这种联系促成时间—温度叠加，把不同温度下、有限仪器窗口内的曲线拼接成更宽范围的主曲线。

叠加的关键假设是热流变简单性：相关松弛模式随温度近似按同一个时间因子移动，谱形状基本保留。若一部分模式来自玻璃化附近链段运动，另一部分来自结合点解离、结晶或相分离，它们可能有不同温度依赖，曲线便不能只靠水平移动重合。需要检验的是重合质量和模式一致性，而不是预先认定所有高分子都可以使用同一移位规则。

Williams、Landel和Ferry在1955年整理非晶聚合物及其他玻璃形成液体的温度依赖，提出常用的WLF关系。移位因子定义为某温度松弛时间与参考温度松弛时间的比值；升温使松弛变快时，这个比值小于1。公式中的温度差可以用开尔文或摄氏度的差值表示，但所有差值与系数必须采用一致单位，绝对温度本身仍应明确。

若移位因子为0.01，意味着该温度下对应过程只需参考温度的百分之一时间；在相同实验角频率下，它对应参考温度下更低的有效频率。将频率轴乘移位因子即可按这个定义比较。模量还可能需要随密度与温度作小幅垂直修正，因此实际叠加要明确水平和垂直处理。参考温度变动时，WLF常数也随定义改变，不应把一组著名数值当成任何材料、任何参考点的固定常数。

靠近玻璃化时，温度小幅改变就可能使松弛时间变化很多数量级，因而材料在室温附近表现出的软硬，对配方、增塑剂和含水量都可能敏感。水既改变溶剂环境，也可能改变局部运动与结合，因此含水样品和干样品的移位不能简单归结为一个温度修正。对于半结晶或发生反应的体系，升温还可能改变结构本身，这时要把热历史与动力学移位分开记录。

主曲线的价值是把实验窗口扩展为有条件的预测工具。例如服役时间比常规实验长很多时，可利用经过验证的叠加关系估算相应响应；若温度范围内已经发生模式重排或降解，就需要重新建立状态对应。把叠加曲线与独立温度测量、分子结构及形态变化相结合，才能确定预测延伸到了哪一种材料状态。

把分子时间尺度用于流动与加工

链能否在流动中恢复原来形状，取决于松弛与外部变形的竞争。若每次形变都很慢，链不断接近当前条件下的松弛状态；若形变持续得很快，取向与伸展会积累。用松弛时间乘剪切速率形成的无量纲数，可以粗略比较两种速度；用松弛时间除以整个过程的观察时间，则描述另一种时间竞争。这些数相近时有时能互相联系，但它们采用的外部时间定义不同。

使用条件作为选定流型与模式的量级判断；多个模式、多阶段过程和大形变需更完整本构描述，无单一普适临界值。

在低速率下，许多聚合物流体出现近似恒定的零剪切黏度。速率提高后，链取向与约束重排可使表观黏度下降，即剪切变稀；拉伸流中则可能由于链伸展出现很强的拉伸应力增长。剪切变稀并不等于分子必然断裂，停止流动后结构常能部分或充分恢复；若确有降解，需要用分子量或化学分析另行判断。不同流型让链经历不同的旋转与伸展，不能用一个剪切黏度值预测全部加工过程。

较大无量纲速率提示线性近似可能不足，却不是一个通用的精确失效阈值。材料有多个松弛时间，不同模式会先后无法跟上流动；形变幅度、流型和有限链长也参与决定响应。特别是小振幅高频振荡，即使频率乘松弛时间很大，也仍然可以保持线性，因为每次形变幅度很小；稳定剪切中持续积累的形变则是另一种驱动历程。用单一最长时间可以做第一步估算，更完整的预测需要合适的本构关系，把应力与变形历史、取向、伸展及约束更新联系起来。

实验解释时还要区分材料响应与流动不均匀。壁面滑移会使仪器认为样品变形更多，边缘破裂会改变有效受力面积，黏性发热会让局部黏度下降。观察流场与样品边缘、改变间隙并控制温度，可以帮助判断一条下降的黏度曲线究竟来自链的重排还是测量几何。对于低模量样品，仪器灵敏度与惯性同样可能限制高低频两端的可用范围。

把这一章用于一个实际材料，可以先在固定温度与小幅度下测松弛或振荡，确定可分辨的时间范围；再结合分子量、浓度和结构，判断Rouse、Zimm或缠结约束各自在什么尺度起作用；最后把这些时间与加工速率、等待时间以及冷却过程比较。预测的对象由此很明确：材料在流动时保留多少应力，停止后多久恢复，界面何时能通过链运动建立联系。

长链的动力学并不是把单个小分子的扩散时间简单放大。连接产生一系列协同模式，流体耦合改变阻力的累积方式，拓扑约束又延缓整体更新。宏观流变把这些层次转成可测的应力、应变、储能与耗散。掌握这种对应关系，才能解释为什么“更长的链”“更高的温度”或“更快的加工”会在不同条件下产生不同的材料结果。
