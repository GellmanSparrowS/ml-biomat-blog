从一个状态到许多可能：相空间、概率与系综

知道一条链或一个粒子在哪里，还不足以预测它接下来怎样运动；只看一次测量，也不一定得到稳定的材料性质。从位置与动量出发，建立状态空间和概率平均，再用能量、热浴和粒子交换说明不同系综。最后比较慢跳转过程中的时间平均与系综概率，理解平衡与观测时间之间的关系。

要预测运动，必须知道哪些量

给一根小弹簧挂上物体，把它从平衡位置拉开再松手。物体经过平衡位置时，既可能向左运动，也可能向右运动；同一个位置并没有唯一决定下一刻的位置。要说明完整的机械状态，还要知道运动方向和速度。经典力学常用动量替代速度，它在简单平移运动中等于质量乘速度。质量相同时，动量越大表示运动越快；动量的正负则记录所选择坐标方向上的运动方向。

用q表示物体相对平衡位置的位移，用p表示相应动量。理想无摩擦弹簧的能量包含运动的动能和形变的势能。动能随动量平方增加，势能随位移平方增加，因此向左或向右拉开同样距离具有相同的弹性代价。势能由当前构型及所规定的相互作用决定；对于这里的保守力，它不依赖物体绕了怎样的路径才到达该位置。这个小系统已经足够说明状态、能量和运动规律的联系。

在高分子模型中，若保留许多珠子的坐标与动量，同样的思想可以扩展到所有珠子。但有效珠子可能代表一组原子，而不是一种真实化学粒子；模型中的力与参数要对应这个分辨率。若把周围溶剂省略，珠子受到的阻力和随机力会使它成为开放的有效系统，不能再把珠子机械能单独当作始终守恒的量。先明确保留了什么，才能判断应该使用哪种运动与统计描述。

相空间是一张完整状态的地图

把弹簧位移作为横轴、动量作为纵轴，一个点就同时记录两个数，表示一个完整状态。物体运动时，这个点沿曲线移动，这张图叫相空间。它不是物体在实验桌上的运动轨迹：桌上物体只沿一条直线移动，相空间却需要两个坐标。无摩擦时总能量保持不变，轨迹沿着能量方程规定的椭圆运行。椭圆的左右两端动量为零，物体暂时停下并转向；靠近中央位置时动量大小更大。

自由度是描述构型所需的独立坐标数。一个没有约束的点粒子在三维空间需要三个位置坐标，N个这样的粒子需要3N个；加上各自的共轭动量，相空间具有6N维。刚性连接、固定键长或其他约束会减少独立自由度。一个有方向的轴对称刚性杆，如果只关心中心位置与杆轴朝向而不分辨绕自身轴的旋转，需要三个平移坐标和两个取向角；若自旋也是独立可观测运动，就需要相应增加状态变量。

高维并不意味着样品生活在额外的物理空间里。它表示我们同时记录了很多独立数值。一个含有十个自由珠子的三维模型，完整相空间可以有六十维，实验容器仍在三维空间中。只画一两个坐标是投影，不同完整状态可以投影到同一个点。由投影看到的轨迹交叉，并不能说明完整确定性动力学给一个状态安排了两个不同未来；被省略的坐标或动量可能不同。

在光滑的Hamilton动力学中，一团初始状态可以拉长、扭曲，但其精细相体积保持不变，这称为Liouville体积保持性质。它说的是正则坐标与动量共同构成的体积，不是实际样品体积，也不是图像投影面积。概率分布可以随流动变细，局部图形变复杂，仍保持这一精细体积性质。若系统有摩擦、外部随机驱动或被约化到部分变量，保留空间中的体积变化需要另行分析。

这张状态地图的作用，是把“哪些状态可能”与“实际从哪里走到哪里”放在同一个框架里。能量、连接方式和边界条件限制可访问区域，运动规律决定在区域中怎样移动。统计描述还要为这些状态赋予权重。即使知道全部允许状态，也不意味着每一个状态在具体实验中同样容易被访问；这正是概率、系综和时间尺度随后要解决的问题。

概率与概率密度怎样使用

对能够逐个编号的状态，可以给第i个状态一个概率。概率必须非负，所有互斥且完整的状态概率相加等于一，这叫归一化。如果一个量在各状态下有不同数值，它的平均值就是各数值乘相应概率再相加。平均不必等于任何一个实际出现的值：一个状态读数为零，另一个为十，等概率时平均为五，尽管仪器每次只读到零或十。平均是重复观测的统计性质，而不是一个被遗漏的中间状态。

算一个例子两个状态分别0 N与10 N，各概率0.5，平均5 N，方差25 N²，标准差5 N。

使用条件离散状态或已定义的状态分组；A也可为其他物理量，均值保持其单位，方差为其单位平方。

波动描述各次观察离平均有多远。先减去平均，再平方以避免正负抵消，最后按概率平均，得到方差；其平方根称为标准差，单位与原观测量相同。相同平均可以伴随不同波动。例如读数总是五与零、十各半，平均相同但稳定程度不同。对于单分子测量、微小样品或靠近相变的材料，波动本身往往包含重要机制信息，不能只把它当作需要抹掉的误差。

连续状态不能简单为每个精确点赋一个相同的有限概率，否则无限多个点相加会出问题。应使用概率密度：一个小区域的概率近似等于密度乘区域大小，对完整区域积分则等于一。积分可以理解为把区域分成许多小块，分别计算概率后相加，并让小块足够细。密度的单位与所用空间体积单位互为倒数，因此密度的数值可以大于一，只要积分后的概率仍在零到一之间。

在弹簧的二维相空间中，一个位移宽度0.2米、动量宽度0.4千克米每秒的矩形，其相面积为0.08焦耳秒。若概率均匀分布于该矩形，密度为每焦耳秒12.5；矩形一半的概率仍然是0.5。数字12.5不是超过百分之百的概率，它必须先乘相面积。改变坐标单位会改变密度的数值，但同一个物理区域的概率不应改变，这个检验能够帮助发现归一化错误。

很多高分子问题会先把连续构象划成可辨识的区域，再统计区域概率。区域可以是末端距范围、螺旋含量范围或某种结合状态。划分必须互不重叠且覆盖所研究的状态集合，或者明确说明还有未纳入的部分。把概率加权平均写清楚，也就说清了实验对哪些状态敏感、哪些状态贡献较多。相空间的几何与概率分布在这里开始共同决定可测的宏观量。

时间平均与系综平均为何需要区分

对同一个样品连续观察，把一段时间内的读数平均，得到时间平均。另一种想法是在相同宏观条件下准备许多独立样品，在同一时刻观察它们，再对读数平均，这就是系综平均。系综不是把许多真实样品必须堆进同一个容器，而是用一组具有相同物理规则和规定条件、不同微观状态的可能系统来表示分布。Gibbs在1902年的统计力学专著中系统发展了这种组织方式，使热力学条件与状态概率能够统一讨论。

使用条件时间记录积分可由足够细采样近似；不预设有限时间平均与系综平均相等。

两种平均何时相同，需要动力学条件。对于合适的平稳分布，各态历经性质意味着长期时间平均对典型初态与相应系综平均一致。它不是要求在有限时间里逐个走过连续空间中的每一个点，也不是单纯等待一会儿就能保证成立。可访问区域可能分成互不连通的部分，也可能由极难跨越的势垒连接。后一种体系在数学上长期可遍历，但实验时间内仍可能只停留在一个区域。

系综平均也不会自动保证数值准确。若独立样本太少、初始分布不正确，或者测量对某些状态有选择偏差，平均仍会偏离目标。重复准备同一种陷入局部状态的样品，不能凭重复次数修复没有采到另一类状态的问题。高分子链的慢松弛、折叠势垒和缠结约束，都使准备历史与等待时间成为统计分析的一部分。先确定要平均的分布，再检查实际采样是否代表它，比只选择一个平均名称更重要。

抽样方法可以用随机的构象改变来探索分布。Metropolis、两位Rosenbluth和两位Teller在1953年的工作，为按目标平衡权重抽样相互作用体系提供了经典方法。对固定长度的链，所有样本保持相同段数；若有意允许链长变化，必须另行规定对应的统计模型。局部转动或交换动作既要给出正确平衡权重，也要能连接需要的状态区域。满足某个接受概率条件，并不自动保证动作集合能够走遍所有相关构象。

格点自避链尤其容易显示这种区别。若每一步始终从四个方向等概率尝试，碰撞便整条重来，固定长度的成功方向序列具有相同初始权重；若每步只在剩余可走方向中选，分支数随历史改变，就可能引入生长偏差，需要相应校正。无论哪种方法，抽样的一步通常不等于真实分子运动的一秒。它首先是访问概率分布的方法，只有配上经过物理标定的动力学规则，才可解释为真实时间演化。

孤立体系怎样给出微正则系综

如果系统不与外界交换能量和粒子，又具有固定容器和不随时间变化的相互作用，总能量可以作为约束。统计描述于是限制在某个能量附近的可访问状态中，这就是微正则系综。实际测量总有能量分辨率，因此常使用很薄的能量壳层，而不是把状态数写成某个精确连续点的数量。壳层宽度应小到不改变所研究的宏观条件，又足以包含用于统计描述的许多微观状态。

等概率原则针对的是采用一致相空间测度定义的允许微观状态，而不是对任意投影坐标都均匀。例如振子在转向点附近移动慢，在位置轴上停留较久，所以平衡的位置概率并不均匀。相空间中的能量曲线与位置投影之间有几何和运动速度的关系。把“等能状态等权”误读为“所有位置等概率”，会失去这层关系。使用能量壳层或相应能量曲面的诱导测度，能保持计数与动力学一致。

宏观热力学量可以从这个受约束的状态集合得到。状态数随能量、体积和粒子数改变，熵便随之改变；不同系统接触后如何分配能量，与总状态数怎样增加有关。因此温度不只是把动能数值换一个名字，它还与状态数对能量的响应相关。在经典可用能量均分的简单体系中，平均动能与温度有直接关系；量子自由度冻结、相互作用和约束改变时，需要使用相应统计描述。

对于理想无摩擦弹簧，如果确定了总能量，却没有确定振动相位，整个系综可以分布在同一条能量轨道上。这与一个能量已知且位置动量也完全已知的单一状态不同。前者的概率反映对状态的统计描述，后者在确定性模型中沿一条确定轨迹演化。即使只有一个粒子，仍然可以讨论这样定义的分布和熵；不能因为粒子数少就断言统计概念失去意义。

高分子材料在实验中常与环境交换热，严格孤立只是一种理想条件。但微正则观点仍有作用：可以把样品加上足够大的环境看作更大孤立系统，再推导样品本身的平衡权重。这样，下一种系综中的指数概率并非任意选择的曲线，而是来自样品能量改变时环境可实现状态数的变化。明确系统与环境的边界，使不同系综成为同一统计逻辑在不同条件下的表达。

热浴为什么给出Boltzmann权重

让样品与一个很大的热浴接触，允许交换能量，但固定样品的体积和粒子数。样品能量会涨落，热浴却大到在交换这些能量后温度几乎不变，这就对应正则系综。将样品和热浴合起来看作孤立系统，样品若多获得一些能量，热浴就少一些能量。热浴在不同能量下具有不同状态数，因而样品不同能量状态的概率也不同。把大热浴的熵在原能量附近展开，便得到指数形式的Boltzmann权重。

指数的输入必须无量纲，所以能量除以玻尔兹曼常数与绝对温度的乘积。玻尔兹曼常数为1.380649乘十的负二十三次方焦耳每开尔文，三百开尔文对应的热能约为4.14乘十的负二十一次方焦耳。配分函数把所有微观状态的权重相加，保证最终概率归一化。它一般不是未加权的状态总数；只有所有所计状态具有相同适当零参考能量等特殊情形，才会直接变成简单计数。

若多个微观状态具有同一能量，计算某个能级的总概率时要把这些状态都算进去。假设低能级只有一个状态，高能级有三个状态，能量差为两个热能单位。单个高能状态权重是低能状态的指数负二倍，三个相加后，高能级总概率约为0.289。虽然高能级单态较少出现，其三个实现方式仍显著增加了总占比。微观状态概率和能级总概率的区别，在有许多构象的分子中尤其重要。

配分函数还把概率连接到热力学。自由能由其自然对数得到，平均内能按状态概率加权，熵则对概率的自然对数加权。概率越分散，通常可访问状态的信息越多；但热力学比较必须保持同样的状态定义和物理约束。熵表达式在只有一个状态概率为一时为零，在Ω个状态等概率时回到玻尔兹曼计数形式。零概率项采用连续极限处理，其对熵的贡献为零。

从连续经典相空间构造配分函数，还需要规定物理的状态计数尺度，并对相同粒子的不可分辨性作一致处理。通常出现由普朗克常数给出的相空间单位和相同粒子置换的修正；这些因素对绝对自由能、熵和化学势很重要。把连续分布随手切成任意大小的格子后直接称其为绝对热力学熵，会把分辨率的改变混入物理结果。本章的离散算例使用明确列出的状态，因此归一化与熵的计算可以直接核对。

允许交换粒子时，化学势进入概率

有些系统不仅交换热，还交换物质。一个吸附位点可能结合或释放溶液中的分子，一小块溶液区域的粒子数会随扩散改变，聚合物凝胶也能吸收或释放溶剂。若它与足够大的热浴和粒子库达到平衡，常用固定温度、体积和化学势的巨正则系综。粒子数不再被固定为同一个值，而是在允许的数目之间涨落。状态必须同时说明有多少粒子以及这些粒子处于哪个微观状态。

化学势衡量在规定热力学条件下增加粒子对相应自由能的边际影响。按每个粒子计量时单位为焦耳，按每摩尔计量时单位为焦耳每摩尔，两种约定要通过阿伏伽德罗常数转换。它不是一个粒子当前携带的动能，也不只由浓度一个数字决定；温度、相互作用和所选参考状态都参与定义。在平衡交换中，粒子库给出的化学势决定增加或减少粒子的统计倾向。

不同系综不是互相竞争的材料分类，而是对同一个系统在不同边界条件下的描述。宏观短程体系在适当热力学极限下，许多局部或平均性质可以在不同系综中趋于一致；有限系统的能量或粒子数涨落仍明显不同。测量一个固定粒子数的小样品和一个能自由交换粒子的区域，本来就问了不同问题。选择系综时，先看实验允许交换什么，再看需要预测哪一种平均或波动。

相同平衡概率，可以有完全不同的等待时间

平衡概率说明长期在不同状态中怎样分配，却不直接给出状态转换有多快。设一个分子有A、B两种构象，B比A的能量高一些。热平衡要求从A流向B与从B流向A的概率通量相等，因而两个转移速率的比值与能量差有关。但把两个速率同时乘以一个很小的因子，会延长所有等待时间，却不改变它们的比值，也不改变最终平衡占比。能量差和跨越势垒分别控制占比与速度。

熵、粗粒化与有限样品

概率熵依赖完整分布，不是某一时刻单个机械坐标的普通函数。一个粒子可以处于具有多个可能位置或能级的分布，因此也可以具有统计熵；许多粒子并不是定义熵的最低人数要求。在给定模型和状态计数下，熵是分布所确定的状态量。它与到达当前平衡状态的具体过程不同，但过程可以改变状态与概率分布。说熵与路径无关，并不意味着温度、体积或能量变化时熵不能改变。

对于相互独立的两个子系统，联合概率是各自概率的乘积，对数把乘积变成和，因此总熵可加。若两个部分具有相关性，联合分布就包含额外信息，不能不加判断地把两个边缘分布的熵相加当成完整熵。宏观短程相互作用体系在边界效应相对小时通常具有良好的广延性，即增大物质量时熵近似同比增加。长度本身并不是所有几何形状下都与物质量同比增长的广延量，温度和压强则属于常见强度量。

粗粒化是把分辨不出的微观细节合并成较大的状态格或少量变量。它可以是空间上的小盒子、有限测量时间，也可以是把大量原子替换为有效链段。粗粒分布保存了被保留尺度的信息，丢掉格子内部或被消去变量之间的细节。Hamilton演化下精细概率可以越拉越细，而固定分辨率的观察会看不到这些结构，因此粗粒熵与精细熵的演化可能不同。热力学不可逆性还涉及初始条件、环境和观测尺度，不能仅凭一个“混乱度”词语替代这些内容。

粗粒模型不是只要把格子做大就更好。格子太小，数据不够，每格几乎都为空；格子太大，关键界面、结合态或慢结构又会被合并。选择尺度时要看目标现象能否被分辨，以及保留变量的动力学是否仍有明显记忆。被省略的自由度如果恢复很慢，简单的无记忆方程可能不够，需要额外状态变量或记忆项。粗粒化的价值在于保留问题所需的可预测关系，并用实验或更细模型校准。

热力学极限通常指粒子数和体积同时增大而保持密度等强度条件固定。它帮助定义尖锐相变和稳定宏观关系，却不是有限系统统计量有意义的前提。少量独立对象的平均波动往往较大，相关性还会改变有效独立样本数。在单分子和纳米材料中，报告分布、方差、相关时间以及准备条件，常比只给一个宏观平均更完整。平均可以越来越稳定，但真正减少误差的是增加有效独立信息，而不只是提高同一条相关记录的采样频率。

相空间告诉我们状态由什么组成，系综说明在何种交换约束下给状态赋权，动力学决定实际观测怎样探索这些可能性。三者结合，才能解释为何同一种材料可以有稳定的宏观性质，又存在持续的微观波动，也能解释为什么等待时间不足时会保留历史差别。把状态定义、归一化、模型条件和时间尺度一起写清楚，便能把统计力学用于真实高分子的形状、热行为与运动，而不把形式上的平均误当成已经完成的物理解释。
