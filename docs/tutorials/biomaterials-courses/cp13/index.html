流动怎样转动分子：高分子液晶的动力学

拉出一根纤维或铺展一层液晶聚合物时，分子不仅移动，还会改变朝向。它们可能稳定地倾斜，也可能持续翻滚；局部排列又会通过弹性、边界与外场形成整幅纹理。从单根杆的转动出发，理解这些运动如何改变流动、光学与加工后的材料结构。

材料流过以后，方向留下了什么

液晶聚合物被挤出成纤维时，沿纤维方向与横向的力学响应可以不同；薄膜流过狭窄间隙后，也可能在偏振光下呈现随加工方向变化的明暗。材料不仅被搬到了新的位置，分子的取向也经历了变化。刚性或半刚性链段更容易在某些条件下形成共同排列，流动、热运动与邻近分子的作用则不断争夺这个排列。加工留下的结构，取决于这些过程谁更快。

向列液晶的局部主要排列方向称为指向矢。对于没有头尾极性的普通向列状态，把它转过180度仍表示相同的轴向排列；画一根短线比画一支具有头尾的箭头更贴切。指向矢描述“多数分子大致沿哪根轴”，并不表示每个分子都完全平行。分布越集中，取向有序程度越高；同一主要方向也可以对应较宽或较窄的分布。

因此至少要区分三种变化。第一，主要方向整体转动，而分布宽度近似不变；第二，分布变得更集中或更分散，有序程度改变；第三，不同空间位置的主要方向不同，形成弯曲、扭转与缺陷等纹理。一个只记录平均角度的模型能解释第一种变化，却不足以完整描述后两种。反过来，一张偏振显微照片把厚度、方向与有序程度混在光学信号里，也不能直接等同于分子的角度分布。

液晶聚合物还具有链连接。刚性主链、带液晶侧基的柔性主链以及半柔性链，在同样流动下会有不同的内部调整路径。液晶基团可以先局部转动，主链构象随后改变；在浓体系中，邻链不能彼此穿过，又会延长整体转动或结构更新的时间。低分子液晶的指向矢理论提供基本框架，高分子材料则往往需要把更多内部慢变量接入。

讨论动力学前，先明确外部如何驱动。简单剪切可以想象成一叠平行液层，越靠上流得越快；伸长流则沿某方向拉开、沿其他方向压缩，二者对取向的作用不同。本章从均匀简单剪切开始，因为它能把液体的局部旋转与伸展作用分开，再逐渐加入热运动、取向弹性、边界锚定和外场。每增加一项，都要问它改变的是转动速度、稳定方向，还是空间上的一致性。

这些问题直接服务材料设计。若希望加工得到高取向纤维，需要在流动中形成目标取向，并在停止后用冷却、结晶或交联把它保留；若希望器件反复切换，则需要较快、可恢复的取向运动。强约束可能稳定结构，也可能拖慢响应。把方向、分布和纹理分层描述，才能说明同一配方为何在不同流动与冷却历史下得到不同性能。

一根杆在剪切流中为什么会转动

把一根细杆斜放在简单剪切流中，杆的两端通常处于不同高度，周围液体速度也不同，因而受到不同的黏性拖曳。结果不仅是质心被液体带走，还会产生改变朝向的转动。剪切流可以分成局部整体旋转与伸展两部分：旋转使一个小物体整体转动，伸展则倾向于改变物体与某些方向的夹角。杆的实际转动来自两者共同作用。

Jeffery在1922年研究椭球颗粒在黏性流体中的运动，把非球形颗粒的几何与转动联系起来。对于稀悬浮液中的孤立轴对称椭球，在低惯性、无热转动和无外场的理想条件下，取向可以沿周期轨道变化。长杆常在接近流向时转得慢、离开流向后转得快，因此时间平均看起来偏向流向，即使它没有真正停止转动。观察一个短时间片段，容易把这种缓慢经过误认为稳定排列。

先把运动限制在剪切平面里，令流动沿x方向，速度随y增大，角度从x轴向y轴量起。角度变化率表示每秒转过多少弧度；弧度把弧长除以半径，属于无量纲角度单位。转动方程中的余弦反映杆与伸展方向的几何关系，角度乘2则保证把杆转过180度后得到相同动力学，符合无头尾轴的对称性。

这里的形状参数只由椭球长短轴比决定，有限长宽比的长杆给出小于1的参数。因此在这一理想平面模型中，转动速率不会在某个角度稳定变为零；它会继续翻滚，只是快慢不均。长宽比增大时，接近流向的停留更久。球形粒子的形状参数为0，所有方向在形状上等价，公式剩下液体局部旋转的贡献；球上的假想标记轴仍可被用来追踪转动。

实际布朗杆还会受到随机转矩；附近墙面、其他颗粒和非牛顿溶剂也会改变运动。三维Jeffery轨道可离开剪切平面，不能都用一个平面角度表示。这个简化模型的用途是建立重要的起点：流动中的取向并不天然等于静止对齐，形状也不只决定一个固定夹角。粒子沿轨道花费的时间分布，本身就能产生明显的平均取向。

从单杆进入向列液晶时，周围分子共同排列并产生相互作用转矩，描述对象也从一个孤立物体变为局部取向场。此时有效流动取向参数不再等同于孤立椭球的几何参数，可以进入允许稳定取向的范围。两类方程虽然形式相近，参数的物理来源与适用条件却不同，需要在下一步明确区分。

稳定倾斜与持续翻滚的分界

向列液晶中的主要方向会受到流动转矩、取向弹性和外场共同作用。Ericksen与Leslie发展的连续介质理论把速度场、应力和指向矢的运动联系起来；Leslie在1968年的本构研究给出了这一类耦合描述的重要形式。先考虑空间均匀、没有边界梯度与外场，并且有序程度近似固定的局部状态，可以得到一个平面指向矢角度方程。它保留了剪切的旋转与取向竞争，适合先理解两种不同运动。

图中的角度曲线保留累计转过的角度，可能低于零；短线则把相差180度的方向视为同一轴。两种画法服务不同目的：前者用来判断是否持续翻滚，后者忠实表示向列对称性。若只把角度强行限制在0到180度，连续运动会在边界产生突然跳变，容易被误读为分子瞬时翻转。反过来，只看一根无头尾短线，也可能漏掉它已经走过多个周期。

对于翻滚区，周期是在指向矢回到同一轴向状态后定义的，即转过180度；若给单根杆人为标记一个头，需要转360度才回到相同带头状态，两种周期差一倍。明确这个约定，才能比较实验轨迹、显微图像与理论曲线。近λ=1时周期变长，小的参数变化就可能显著改变观察窗口内的行为。

真实液晶还可能出现往复摆动、离开剪切平面的转动、取向程度周期变化，以及空间不均匀的流动纹理。这些运动需要允许更多自由度，不能由当前一个角度、固定有序程度的均匀方程全部给出。简单交互的作用，是把稳定取向与无固定角度翻滚的机制明确展示；加入分布与空间变量后，才能继续讨论更丰富的高分子液晶响应。

热转动、分子拥挤与取向分布

真实分子的朝向不是一个确定不变的角度。热运动不断施加随机转矩，使分子转向；流动与相互作用则改变不同方向出现的概率。取向分布描述有多少分子朝向某个角度范围，范围越窄、出现比例越高，局部排列通常越集中。对于三维空间，均匀各向同性意味着相同立体角有相同概率，而不是极角从0到180度的每个等宽区间都一样常见，因为赤道附近对应的方向更多。

一个常用的二阶取向参数，把分子长轴与局部主要方向的夹角进行统计平均。完全平行或反平行都给相同贡献，符合无头尾对称；三维各向同性分布给零。计算前要先说明参考轴和分布维数：若所有杆被限制在一个平面，即使它们在平面内均匀散开，也不同于三维各向同性。不能把平面示意图的平均值不加转换就代入三维定义。

在稀体系中，转动扩散系数描述热运动使方向散开的速度，它与转动阻力通过热能联系起来。流动速率与转动扩散的比值称为转动Péclet数，用来判断流动对分布的扰动是否容易超过热转动。这个比较不能单独决定体系是否形成平衡向列相：平衡有序还取决于浓度和分子间相互作用，即使没有流动也可能存在。

Doi在1981年的分子理论中，把浓杆状聚合物的转动分布与应力联系起来，统一讨论各向同性与液晶状态的流变。分布既受流动转动，也受扩散与取向相互作用影响，彼此竞争后产生随时间变化的平均应力。浓体系里，一根长杆改变朝向需要周围分子提供可达空间，转动因而可能比沿自身方向平移困难得多。Doi与Edwards在1978年对浓杆溶液的研究已经强调这种不能相互穿过的动力学约束。

这也解释了为什么停止流动后不一定出现一个简单指数恢复。局部角度扩散、分布宽度变化、整体畴方向转动以及链构象调整，可能有不同时间。半柔性链还可以通过弯曲改变局部取向，并不需要像完全刚性的整根杆那样协同旋转。把测得的一个衰减时间称为“转动时间”之前，需要说明它来自双折射、应力、散射还是单分子跟踪，因为这些观测对不同模式的权重不同。

方向在空间中改变，要付出多少代价

若一个区域的分子沿水平方向排列，相邻区域却沿竖直方向排列，连接两者的过渡区必须发生取向畸变。向列液晶可以流动，但仍会抵抗这种方向随空间变化的结构。这里的弹性不是要求分子质心固定在晶格上，而是偏离均匀取向需要自由能。展曲表示方向像扇面一样张开，扭曲表示沿某个方向逐层转动，弯曲则表示方向线本身拐弯；三类畸变一般具有不同的弹性常数。

Frank在1958年系统整理液晶取向弹性的连续理论，把这类空间变化写进自由能。为了先看清尺度关系，可以把不同畸变的弹性常数近似为同一个K，得到单常数模型。空间导数表示相邻位置的方向变化率，平方使正向与反向畸变都具有非负代价；积分把整个体积内的局部代价相加。K的单位是牛顿，也可以写成焦耳每米。

同样的总转角若被压缩到更薄的区域，方向梯度更大，单位体积弹性能也更高。因此取向通常愿意平滑过渡，而边界锚定或拓扑条件又可能阻止完全均匀。缺陷核心处，指向矢可能失去清楚定义，有序程度也会降低；只用固定长度指向矢的平滑梯度自由能，会在某些缺陷附近出现奇异性。描述核心需要允许取向程度变化，或明确一个微观截止尺度。

弹性决定恢复的驱动力，转动黏度决定恢复时的阻力。取一个夹在两平板间、边界方向固定的样品，撤去扰动后，小角度畸变会逐渐消失。最慢的平滑恢复模式横跨整个厚度，时间与转动黏度乘厚度平方成正比，与弹性常数成反比。它和扩散的距离平方时间关系相似，因为恢复依赖空间梯度驱动的连续重排，而不是整个样品瞬时同步转动。

厚度增加十倍，在相同参数和强锚定条件下，这个模式的时间增加一百倍。高分子液晶的转动阻力常较大，还可叠加主链或缠结的慢过程，因此局部方向已明显改变时，整幅纹理仍可能缓慢演化。测量厚度依赖有助于区分单分子局部转动和由边界控制的大尺度恢复；若响应不符合平方趋势，则需要检查锚定、流动耦合或其他慢变量。

流动转矩与弹性转矩也可以通过一个无量纲比例比较。剪切推动取向变化，弹性则维持空间平滑，两者竞争决定边界影响能传多远以及是否容易形成非均匀结构。这个比例随样品尺度平方变化，说明在相同剪切速率下，大体积样品与薄膜可能处于不同的纹理响应范围。几何尺寸不仅改变实验便利性，也进入了动力学本身。

边界与外场怎样选择方向

把液晶夹在两块表面经过处理的平板之间，表面往往偏好某种局部方向，这种作用称为锚定。偏好平行表面时，还可能指定平面内的一条方向；偏好垂直表面时，则形成另一种边界条件。锚定并非无穷大的命令，真实表面只对偏离偏好方向施加有限自由能代价。表面化学、粗糙度与邻近聚合物层，都可以改变锚定强度与偏好方向。

强锚定近似把边界方向固定，内部方向只能通过空间弯曲来适应外部驱动。若两块平板偏好不同方向，液晶即使没有流动也可能保持扭转或弯曲结构。弱锚定时，边界本身可以转动，内部与表面共同分担变形。于是同样厚度、同样外场的两只样品，可能因表面处理不同而具有不同阈值与恢复速度。把边界条件写清楚，是判断取向动力学的组成部分。

电场或磁场通过材料的各向异性产生取向转矩。以介电各向异性为正的向列液晶为例，电场倾向使主要方向沿场排列；表面与弹性则可能偏好另一方向。外场足够弱时，均匀边界取向可以保持稳定；场增强到一定程度后，内部开始偏转。Fréedericksz与Zolina在1933年对使各向异性液体取向的力进行了研究，这类场驱动重排成为认识液晶弹性与控制取向的重要途径。

公式对应一个明确的几何：两板初始都使指向矢平行板面，电场垂直板面，边界强锚定，内部小角度偏转由一个弹性常数描述。阈值电场随板间距的倒数变化，而阈值电压在这一近似下与间距无关，因为电压等于均匀电场乘间距。这种抵消来自弹性与场能的特定空间标度；有限锚定、非均匀电场或离子效应会改变结果。

开启与关闭外场不一定具有同一个时间尺度。关闭后，主要由弹性驱动回到边界偏好的结构；开启时，电场增加了新的驱动力，离阈值多远也会影响增长速度。接近阈值时，净驱动力较弱，响应可以很慢。若材料导电或有可移动离子，还可能出现电荷积累、屏蔽和电流发热，需要把实际施加到液晶内部的场与电源电压区分开。

指向矢转动也能反过来驱动液体运动，称为回流耦合。它来自取向应力与流体动量之间的相互作用，不要求外部持续推动平板。因此某些切换过程会出现比纯角度扩散更复杂的时间曲线。若把速度场完全固定为零，就相当于忽略这项反馈；在能够近似压制流动的几何或慢过程里可能合理，在快速切换时则需要检验。

对高分子液晶，外场选择的是局部液晶取向，而主链与缠结环境可能随后才调整。取向看起来已经接近目标方向，并不意味着机械应力也完全消失。把光学变化与力学松弛同时记录，可以观察这两种恢复是否同步。这样的联合测量有助于决定场驱动结构应该等待多久再固定，或器件在下一次切换前是否已回到可重复的初始状态。

怎样同时读懂流变曲线与光学图像

液晶的黏度依赖主要方向相对于流动的关系。相同剪切速度下，分子沿流向、沿速度梯度方向或沿二者垂直方向排列，可以产生不同的应力。Miesowicz在1946年报告用磁场维持取向时的三种主要黏度，明确区分了“在指定方向下测到的黏度”和“流动自己改变方向后得到的表观值”。如果测量过程中指向矢正在转动，一个随速率变化的黏度就同时包含本构阻力与取向重排。

因此，液晶聚合物的剪切变稀可以与畴的排列、局部方向变化和链构象调整有关，不能只用一个分子摩擦系数的下降来解释。启动剪切后，应力可能先升高再下降，也可能在某些条件下振荡；这些信号可能对应取向或分布的过渡运动。解释之前需要检查流场是否均匀、边界是否滑移、温度是否稳定，并把力学信号与同时观察到的结构变化对应。

偏振光提供了一种敏感的取向读数。普通光包含不同振动方向，起偏器先选出一个方向，检偏器再选择另一方向。对于具有均匀光轴的双折射薄层，沿两条主光学方向传播的光具有不同相位速度，出射时积累相位差。把检偏器与起偏器垂直放置，就能把取向角与相位差转成透过光强。双折射是两个相应折射率的差，折射率本身是无量纲量。

公式说明暗区并不只有一种含义。光轴恰好与偏振方向平行时，即使液晶有序程度很高，也可以完全暗；当厚度与双折射使相位延迟达到某些整数周期时，也会暗。转动样品后出现明暗交替，通常提示取向而非单纯材料消失。反过来，一个亮区也不能直接表示所有分子更平行，因为厚度、波长与取向角都参与强度。因此判断有序程度通常需要校准或更多观测。

纹理中的条带、刷纹或缺陷附近的暗线，可以帮助识别方向在空间中的变化，但显微镜看到的是沿光路累积的信号。若厚度方向发生扭转，简单均匀薄层公式就需要扩展；若材料散射很强或有吸收，透射强度还受到其他因素影响。对动态过程，曝光时间也会把快速翻滚平均掉，使本来变化的纹理看起来较稳定。图像与时间分辨率必须一起解释。

流变—光学联用的优势，是可以比较应力变化与方向变化谁先发生。例如启动流动后双折射先变化而应力继续缓慢调整，可能意味着局部取向与更大尺度链或畴运动具有不同时间；如果应力突变伴随流场局部化，则要检查空间非均匀性。这样的比较提出可检验的结构解释，而不是仅给曲线上的峰起一个名称。

还可以加入散射来区分局部有序与畴排列。很多小畴各自排列很好、方向却彼此不同，宏观平均可能接近各向同性；把畴旋转到相近方向，会大幅改变宏观双折射与流变，而每个畴内部的有序程度未必同样增加。这个例子再次说明，方向分布的空间层次决定观测含义：分子、局部畴与整个样品的平均不能混为一个取向参数。

把流动取向变成可保留、可恢复的结构

加工液晶聚合物时，形成取向只是第一步。流动停止后，热运动、弹性与边界会继续改变结构；随后冷却、溶剂移除、结晶或交联又会逐渐限制运动。最终保留的方向，是取向建立、松弛和固定三种过程共同作用的结果。若固定发生得很早，局部缺陷与不均匀分布也可能一起留下；若等待太久，想要保留的宏观取向又可能部分消失。

以纤维为例，出口附近的拉伸流有利于某些方向的排列，但进入冷却或凝固区后，速度梯度与温度会不断改变。表层往往先固定，内部仍能调整，因而可能形成皮芯差异。薄膜中的两面锚定不同，又可能把流动得到的均匀方向改造成厚度方向的转动。只报告最终拉伸比或一个剪切速率，难以完整描述这些连续变化的历史，需要把实际流型、停留时间和固化过程联系起来。

若目标是可逆响应器件，设计问题则变成怎样让结构有明确的返回路径。边界锚定可以提供参考方向，取向弹性传递恢复作用，外场控制偏转，黏性与链内部运动决定速度。提高场强可以加快某些开启过程，却不一定同比加快关闭过程；减小厚度可以缩短弹性恢复时间，又会改变机械强度、光程与制造要求。选择参数时需要同时考虑目标光学或力学输出，而不是只追求最短局部转动时间。

一个有用的实验顺序，是先在静止状态确认局部相态和纹理，再以小扰动测恢复时间与厚度依赖，随后逐步提高流动或场驱动，观察稳定倾斜、翻滚或空间非均匀性何时出现。停止驱动后继续跟踪光学、应力与形态，识别哪些变化可恢复、哪些被慢过程保留。这样得到的状态图同时包含驱动条件和观察时间，而不把所有未变化的图像都当成平衡态。

数据比较还应使用同一角度与符号约定。剪切方向反转会改变稳定角度的符号，指向矢相差180度仍代表同一状态；光学角度则相对于偏振轴，而理论角度常相对于流向。把这些轴画在实验示意图上，能够避免把同一取向写成互相矛盾的数值。对于三维运动，至少需要说明观测投影；平面投影的角度变化并不总等于真实轴在三维空间转过的角度。

高分子液晶的特殊之处，在于流体运动、分子排列与链连接同时参与响应。单杆的几何转动说明流动为什么能产生平均取向；集体指向矢与分布理论说明稳定排列和时间变化如何出现；取向弹性与边界则把局部运动组织成整幅纹理。把这些层次与加工时间对应起来，就能更清楚地解释材料如何形成方向性，也能设计它在需要时保留方向、在需要时重新改变方向。
