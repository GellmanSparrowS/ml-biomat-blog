会流动也会回弹：看懂高分子的黏弹性

塑料为什么会慢慢变形，熔体为什么会记得刚经过的口模？从力、形变与速率讲起，用松弛、蠕变和振荡实验追踪长链的时间尺度，再把温度、流动失稳与仪器测量联系到真实加工。

一块材料为什么会有不同的时间表

塑料卡扣刚扣上时很紧，放置一段时间后夹持力可能下降；一条橡皮带快速拉伸时明显反抗，慢慢拉则给分子更多调整机会；熔融塑料离开细口模以后，还可能向侧面膨胀。这些现象把“固体会回弹”和“液体会流动”连接起来。材料既能暂时储存变形带来的能量，也能通过内部运动耗散能量，这种同时具有弹性和黏性的行为称为黏弹性。知道它怎样随时间变化，才能安排密封、减振、挤出、纺丝和长期承载。

弹簧和缓慢移动的活塞提供两个容易观察的参照。理想弹簧受力后变形，卸载后把储存的能量交回来；装有黏性液体的活塞持续受力时会继续移动，机械功逐渐变成热，卸载后不会自动返回原位置。聚合物里没有真的装入这些零件，它们分别代表能够储能和能够流动的响应。把两种元件连接起来，可以看清一个加载动作中哪些部分立即发生、哪些部分需要等待，以及停止施力以后哪些形变还会保留。

分子是由原子通过化学键相连形成的对象，聚合物分子则往往长得像能够弯曲的链。链上的一小段可以通过键的转动改变方向，较长范围的链又需要邻居让出空间，整条链更要经过许多局部调整才能改变所在位置。因此，材料拥有一系列不同的运动时间，而不是一个统一的“反应速度”。链缠结是长链无法轻易互相穿过造成的运动约束，化学交联则是链之间的持久连接，两者对长时间流动的影响不同。

观察时间短于某种运动所需的时间时，那种运动来不及释放应力；等待足够久以后，它便可能显著改变受力状态。这里“来不及”不等于所有分子停止运动，而是某些能松弛本次变形的运动尚未完成。未交联熔体最终可以通过整链迁移持续流动，稳定交联网络则能保留平衡支撑。温度、分子长度、支化、填料和水分都能改变这些时间尺度，所以同一材料在不同测试速度下出现不同刚度，是可以理解和测量的结构响应。

玻璃化温度附近的变化与长期流动也要分开。玻璃化描述链段运动在所选测试时间内是否足够活跃；整条链摆脱邻居约束通常需要更久。半结晶材料还受到晶体固定，熔化前后的连续载荷路径会改变。所谓流动温度往往依赖施加的载荷和观察时间，并非每种无定形聚合物都具有一个像纯物质熔点那样固定的流动界限。分解同样取决于温度与停留时间，因此加工窗口需要同时考虑流动速度和化学稳定性。

流变学研究材料怎样变形和流动，既包括小幅扰动下的线性响应，也包括加工中明显改变分子取向与组织的非线性过程。线性在这里表示响应与输入幅度成比例，并允许不同小加载的响应相加，并不表示响应没有时间依赖。先建立应力、形变与速率的共同语言，再比较持续加载、突然固定形变和周期振动，许多看似奇特的高分子行为就能放到同一条逻辑中。

把力、形变和变化速度分清楚

手掌垂直压在桌面上，与沿桌面推一本书，作用方向不同。作用在一个面上的力除以该面的面积，得到应力；垂直于面的分量叫法向应力，平行于面的分量叫剪切应力。一个点附近可以选不同朝向的小面，每个面又有不同方向的力，所以完整应力状态需要一组分量来描述。二阶张量就是按明确坐标变换规则组织这组分量的方法，常写成三行三列的表，而不只是一个“很大的数字”。

若用x表示流动方向、y表示速度变化方向、z表示第三个互相垂直方向，σxy可以约定为作用在法向为y的面上、沿x方向的应力。下标约定有时因书写习惯不同而交换，使用前把面与力方向说清楚即可。质量只有大小，是标量；速度同时有大小和方向，是矢量；应力还要回答“在哪个方向的面上”，所以需要张量。法向应力并非只属于弹性，剪切应力也并非只属于黏性，具体响应要由材料关系决定。

简单剪切可以想成把一叠卡片的顶面向右推，底面保持不动。顶面位移除以上下间距，给出剪切应变；若顶面以恒定速度移动，速度除以间距就给出剪切速率。应变描述已经变了多少，速率描述每秒又增加多少。真实流体内的速度可能并非直线分布，此时需要比较相邻层速度随位置的局部变化，称为速度梯度。下面先用均匀间隙、无滑移的平板示意建立单位和数量感。

拉伸流与剪切流也不能混为一谈。剪切中速度方向与主要梯度方向垂直；单轴拉伸中，沿拉伸方向越靠前的物质移动得越快，速度变化与拉伸方向一致。通过收缩入口、吹膜、纺丝或拉细液丝时，拉伸响应常直接影响稳定性。两个熔体即使有相近的剪切黏度，也可能有不同的拉伸黏度和抗拉细能力。测量或建模时，应先匹配实际变形模式，再比较数值。

理想线弹性把应力与当前小应变直接联系，卸载后立即恢复且没有损耗；真实橡胶可以大幅伸长，链形变化带来的熵弹性成为主要恢复机制。熵衡量微观构象的数量，拉直链会减少可选构象，因此热运动产生回缩倾向。稳定网络的理想熵弹性模量可随绝对温度升高而增加，但真实材料还受到体积变化、硬区软化、结晶和降解影响。时间相关的恢复与损耗属于其黏弹部分，不应当作所有理想弹性本身都必须具备的特征。

剪切越快越容易流，是什么意思

牛顿流体在给定温度和压力下，剪切应力与剪切速率成正比，二者比例就是黏度。黏度单位帕秒把应力与变化速度联系起来，数值越大，维持同样剪切速率所需的应力越大。水和许多小分子液体在常见实验范围内接近这种响应。聚合物熔体在很低速率下也常有近似恒定的零剪切黏度，因为分子来得及在持续扰动间调整，整体结构只受到较小偏离。

速率增加后，链取向、伸展与缠结约束的动态更新可能赶不上恢复，黏度开始下降，称为剪切变稀。黏度下降并不等于所需推力下降：应力仍可能随着速率增加，只是增加得没有牛顿比例那么快。描述一段有限范围时，幂律关系很方便，它用一个指数表示应力随速率增加的快慢。幂表示重复乘法的推广，例如速率增加十倍、指数为一半，应力只增加到原来的平方根十倍。

使用条件稳态、等温且适合幂律的有限速率范围；不直接描述低速平台、启动记忆、滑移和失稳。

幂律只是流动曲线的一段。把剪切变稀的幂律一直推到零速率，会得到不断增大的黏度，无法表示实际的低速平台；一直推到无限高速，也会忽略分子伸展极限、温升和失稳。有些模型含第二个高剪切平台，但许多聚合物熔体在实验可达范围内先出现滑移、表面破坏或其他效应。不能把任何高剪切平台都解释成“所有缠结完全消失”，也不能把强流动下暂时变化的约束直接写成链已经断裂。

剪切变稀描述稳定状态下速率改变的影响，触变则强调在同一速率下结构随时间变化，停止扰动后还要逐渐恢复。二者可能同时出现。高浓度颗粒分散体系还可能剪切增稠：应力升高使润滑分隔的颗粒转而形成更多摩擦接触，接近拥挤极限时流动阻力会明显增加。Wyart与Cates在2014年的模型把这种接触转变与不连续增稠联系起来。颗粒形状、表面作用和浓度共同控制结果，不能只用“液体来不及填满空隙”解释所有增稠。

非牛顿行为比“黏度随速率变化”更宽。一种流体的稳态剪切黏度可以在某个范围内近似恒定，却仍表现出应力松弛、拉伸弹性和法向应力差，这类近恒黏度弹性液体常用于把黏度变化与弹性影响分开研究。反过来，单纯用一个随速率变化的黏度函数拟合剪切变稀，并不会自动得到记忆效应。选择模型时，需要先确定它是否保存加载历史，而不只检查它能否穿过一组稳态数据点。

分子结构改变的是整条流动曲线。对于化学结构相同、分布较窄的线型链，超过缠结相关的分子长度范围后，零剪切黏度对分子量会特别敏感；常见经验幂指数约在3至3.4附近，但不同分布与测量区间会改变表现。缠结分子量描述网络约束的链尺度，与黏度曲线开始明显偏离低分子量规律的交叉分子量并不必然相同。少量很长的链能明显延长慢松弛过程，宽分布也不能一概称为更容易加工。

长链支化可改变松弛路径和拉伸硬化，短支链的影响则要在相同主链长度、组成与温度下比较。填料可能增加流动阻力并形成会被剪切破坏的网络，使剪切变稀更强，也可能在高浓度下增稠；不能普遍断言填料总使流体更接近牛顿行为。增塑剂或油会改变链段摩擦、相互作用和有效浓度，同时可能带来迁移与相分配。用分子结构解释黏度，首先要说明保持了哪些比较条件。

固定形变与持续施力：两种时间实验

先迅速拉开一条材料并固定长度，然后记录力怎样随时间下降，这是应力松弛。固定的是形变，内部链却仍能调整，让维持同一形状所需的力减小。另一种实验保持力或应力，记录形变怎样继续增加，称为蠕变。两种实验分别接近卡扣夹持与长期承载的问题，不能把它们的曲线简单当成同一个量的倒数。在线性黏弹性中，两者有数学联系，但通常不是每个时刻的模量和柔量直接互为倒数。

1867年，Maxwell在关于气体动力学的研究中引入应力随时间松弛的思想，把短时弹性与长期流动联系起来。今天常用一个弹簧与一个黏性阻尼器串联来表示单一Maxwell模式：两者承担同样应力，总形变由两者相加。突然固定总形变时，阻尼器继续缓慢移动，弹簧随之缩回，弹簧中的力逐渐降低。图中的机械元件是对这一时间逻辑的现代表示，并不是聚合物分子的真实结构图。

怎样理解串联时弹簧与阻尼器应力相同；固定总形变后阻尼器移动使弹簧缩回，产生按剩余值比例衰减的指数过程。黏度除以模量给秒这一时间量纲。

算一个例子G₀=100000 Pa、η=1000000 Pa·s给τᴹ=10 s。γ₀=0.01时初始应力1000 Pa；t=10 s时约367.88 Pa，20 s时约135.34 Pa。

使用条件小应变、等温、单一线性模式，阶跃输入比所研究松弛快。真实分布或稳定平衡网络需要更多模式或平衡弹簧。

指数衰减表示每经过相同时间，剩余应力按相同比例减少。松弛时间是应力降到初始值约36.8%所需的时间，不是突然完全失去弹性的截止时刻。若松弛时间为10 s，等到10 s和20 s时，仍分别保留约36.8%和13.5%的该模式应力。真实聚合物常有很多模式，短链运动、链段运动、缠结释放和不同相结构提供不同时间，所以测得曲线通常比一条指数更宽。

对同一串联模型施加恒定剪切应力，弹簧立即变形，阻尼器则继续按恒定速率流动，于是蠕变包括一个即时部分与一个随时间增加的部分。卸载以后，弹簧部分可以恢复，而阻尼器已累计的流动保留下来。这个简单结果非常适合理解未交联流体的长期趋势。若要描述有稳定平衡形状的固体，需要在模型中加入能长期承担应力的连接，而不是让所有通路都通过能够无限流动的阻尼器。

使用条件线性、等温单一Maxwell流体。J(t)通常不是同一时刻G(t)的倒数；稳定固体的长期蠕变需要其他网络结构。

把弹簧与阻尼器并联，可以表示逐渐接近有限形变的迟滞响应；把多个模式组合，可以分别安排即时弹性、延迟恢复和不可逆流动。模型的用途是把实验现象拆成可检查的时间过程，不是仅凭拟合出几个元件就认定每个元件对应一种独立分子结构。尤其当形变很大、结构被破坏或出现屈服时，在线性范围得到的参数可能随加载历史改变，需要在相应条件下重新描述。

做松弛或蠕变实验时，还要确认输入真正保持稳定。试样拉长变细以后，恒定力未必等于恒定真实应力；夹具滑动会被误读成材料蠕变，温度漂移也会移动整条时间曲线。卸载后的等待时间决定哪些慢恢复已被观察到。把加载幅度、温度、保持时长和恢复时长写清楚，才能把材料本身的时间响应与设备、几何和操作造成的变化分开。

轻轻来回摇动，读出储能与损耗

除了突然加载，还可以让材料以很小幅度来回剪切。正弦波是一种平滑重复的变化，振幅描述最大变化量，频率表示每秒重复多少次。材料的应力响应通常与形变不同步，这种相位差把可恢复储能与耗散联系起来。储能模量G′描述与形变同相的部分，损耗模量G″描述与形变速率同相的部分。二者单位都是帕，分别告诉我们这一频率下两种响应各有多强。

先保持频率，逐渐改变振幅，可以找出模量基本不随振幅改变的线性范围；随后在这个范围内扫描频率，才能把频率变化主要解释为时间尺度变化。若振幅太大，填料网络、硬区或链取向本身会变化，测到的就同时包含结构重排。仪器能否准确测到很小力矩，试样边缘是否完整，惯性是否开始影响高频，也都会限制曲线中可信的部分。合适的频率范围来自试样和仪器共同决定。

有时把振荡测得的复黏度与稳态剪切黏度对照，会发现形状相近，这类经验联系通常称为Cox–Merz关系。复黏度由储能和损耗共同决定，它属于小幅周期测试；稳态剪切则可能持续改变分子取向，两者不是定义上相同的实验。许多均匀聚合物熔体在适当范围内满足经验对应，含填料网络、凝胶或明显多相组织的材料可能偏离。对实际配方，应先用重叠范围的数据检验对应，再决定怎样扩展使用。

把流变与结构测量同步进行，还能观察力学变化对应什么组织。例如升温时某种微区消失，低频弹性也随之下降，就可以继续检验该微区是否承担慢松弛网络；若散射显示结晶逐渐出现，同时模量上升，则可研究晶体如何限制链运动。单独的模量峰可能有多种原因，结构与时间同时变化的证据让解释更加具体。流变的长处正在于把分子运动、相结构与加工中能够感受到的力联系起来。

温度怎样移动材料的时钟

升温通常使链段更容易跨过局部运动障碍，许多松弛过程加快。若不同松弛模式都按近似相同比例变快，就可以把不同温度下的曲线沿对数时间轴移动，拼成参考温度下更宽的时间范围，这称为时温叠加。高温下较短时间内完成的过程，可以对应较低参考温度下较长的等待。这里改变的是材料完成过程所需的时间，不是说升温让松弛时间变长。

1955年，Williams、Landel与Ferry研究多种无定形聚合物及玻璃形成液体，把温度平移因子与距参考温度的差联系起来。今天常用WLF关系表达这种变化。平移因子定义为某温度的松弛时间除以参考温度的松弛时间；升温使过程加快时，该比值小于1。明确这个定义以后，时间轴应朝哪边移动就可以直接判断，而不必记忆一句容易反过来的口号。

爬杆、胀大与表面裂纹：流动也会储存应力

把杆放进液体中旋转，普通惯性效应常使液面远离轴线的区域升高；一些聚合物溶液却会沿杆向上爬。Weissenberg在1947年的连续介质讨论中把这类现象与流动中的应力联系起来。沿绕杆方向的拉伸作用类似收紧的环带，产生向内的作用，配合重力、表面张力、黏性与惯性决定液面形状。爬升高度不能只由一个“黏度大”来解释，关键在于不同方向的应力不相同。

在约定的简单剪切坐标中，比较流动、梯度与第三方向的法向应力，就得到第一和第二法向应力差。各方向共同含有的静水压力在相减时抵消，使方向性应力更容易显现。理想牛顿流体在简单剪切中没有这种法向应力差，但在其他变形模式中仍能存在黏性法向应力；因此，不能把“存在法向应力”直接等同于“材料具有弹性”。测量需要说明流场与坐标，而不是只看应力分量的名字。

挤出胀大是另一种流动记忆。熔体在入口收缩与口模内剪切时形成取向和可恢复变形，离开壁面约束后发生重排，截面可能比口模出口更大。流速分布重新调整、表面张力、牵引与冷却也会影响最终尺寸，少量胀大并不是高分子独有的现象。工程上比较的是给定口模、温度和流量下的胀大比，并留意离口距离及是否受到牵伸。高分子通常更显著的可恢复应力，使这些条件尤其重要。

液丝在拉伸中能够维持连接，使某些溶液表现出无管虹吸、拉丝或侧壁虹吸现象：已经被带起的液体通过拉伸应力继续牵引后方液体。这个现象说明剪切测试并不能覆盖所有加工行为。纺丝需要液丝既能被拉细，又不至于过早失稳断开；吹膜也需要抵抗局部变薄继续扩大的能力。长链支化、分子量分布与温度对拉伸硬化的影响，可能与它们对稳态剪切黏度的影响不同。

当流动变快，挤出物表面可能出现鲨鱼皮状粗糙，随后也可能出现黏滑振荡或整体畸变，但顺序随材料与设备而变。入口、壁面和出口是不同的潜在扰动位置：收缩入口有强拉伸，壁面有吸附与滑移转换，出口表层要从受壁面约束的慢速状态加速。高速显微观察已经在一些聚乙烯条件下看到出口附近的内聚破坏，因而“熔体破裂绝不涉及真实断裂”并不准确；也不能把所有畸变都统一称为弹性湍流。

改善加工需要先定位机制。若主要来自出口表层拉伸，应考虑出口几何、表面条件与温度分布；若来自入口应力集中，则检查收缩形状和入口流动；若伴随周期压力变化，则同时检查滑移、供料和设备控制。加工助剂可以改变壁面作用，但效果依材料、停留历史和表面覆盖而变。升温能够降低某些应力，却也可能降低熔体强度并加快降解，所以温度调整应与流量、外观和材料状态一同评估。

流变仪怎样把压力、转矩变成材料曲线

毛细管流变仪用活塞把熔体推出细管，记录体积流量与压力。管内壁面剪切力与压力推动力平衡，可以得到壁面剪切应力；这一步来自力平衡，不必先假设流体是牛顿型。把体积流量换成壁面剪切速率则需要速度分布信息。若直接采用牛顿抛物线分布，得到的是表观速率；对幂律流体，可用Rabinowitsch–Mooney修正调整到相应壁面速率，再计算黏度。

实测压降还包括流体进入细管与离开细管时的附加损失。1957年Bagley针对聚乙烯毛细管流动研究端部修正，提出用相同直径、不同长度的管在同一流量下比较压力。若充分发展区的压力损失随长度近似成正比，把总压降对长度作图并外推到零长度，截距就提供端部贡献的估计，包含实验布置中的入口及可能的出口贡献。先扣掉它，再计算管内应力，避免把入口拉伸都算成剪切阻力。

这种修正也有明确条件。若不同长度的管使温升、降解或滑移状态改变，压降—长度关系可能弯曲，不能强行用一条直线遮盖变化。壁面滑移使实际速度在壁处不为零，此时单独修正非牛顿速度分布还不够；可通过改变管径、表面或独立速度测量进一步检查。压力相关黏度、惯性和黏性发热在相应条件下也要纳入。毛细管测试接近加工速率，却仍需要把设备造成的流场与材料本构分开。

旋转流变仪则让试样位于转子与固定表面之间，由转速、角位移、转矩与法向力推算响应。小锥角的锥板几何使间隙与半径一起增大，而局部速度也随半径增加，因此理想情况下剪切速率近似均匀。平行板更容易调整间隙，但速率随半径变化，需要相应处理。锥板也并非永远无需修正：截锥间隙、温度、装样量、边缘破裂、蒸发、滑移与仪器惯性都会改变测量。

转矩是力使物体绕轴转动的作用尺度，离轴越远的同样切向力贡献越大。旋转仪器记录的是整个接触面贡献相加的结果，换成局部应力时必须知道几何尺寸与应力分布。间隙设定误差会改变推算的速率，样品温度与显示温度的差别则会改变黏度本身。用合适的参照流体检查仪器，并在目标温度下确认试样真正达到稳定，能把曲线变化更可靠地归到材料上。

选择测试方法应从实际问题出发。需要低速黏度与小幅松弛谱，可用旋转和振荡；需要接近挤出条件的高剪切响应，可用毛细管；需要纺丝或吹膜稳定性，则增加拉伸流变。相同试样在不同仪器的重叠范围应尽量相互对照，同时记录真实温度、含水状态与热历史。材料在仪器中等待时也可能交联、结晶或降解，因此先观察随等待时间的稳定性，才能安排后续扫描。

读一张流变图时，可以按三个问题检查它的含义：施加的是力、形变还是速率，观察的时间或频率是多少，材料结构在这段过程中是否保持同一种状态。满足这些条件以后，曲线才真正连接到链运动和加工行为。黏弹性提供的不是一个把材料永远分成固体或液体的标签，而是一组可测量的时间关系，让我们知道它何时能够储能、何时能够流动，以及怎样把两种能力用在需要的位置。
