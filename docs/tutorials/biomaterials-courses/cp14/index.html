均匀材料怎样长出花纹：失稳、图案与尺度选择

一层均匀聚合物溶液可以变成互相连通的两相网络，平整薄膜可以长出孔洞，连接在同一条链上的两种链段又能排成纳米条纹。沿着微小起伏被放大、不同尺度彼此竞争和结构逐渐固定的过程，理解材料为什么出现图案，以及怎样用加工条件改变它。

图案首先是材料怎样分布

制造多孔膜时，可以先把聚合物溶解成均匀液体，再改变温度或溶剂环境。随后出现的聚合物富集区与贫化区，可能分别成为孔壁和孔道。透明涂层却常希望避免同样的过程，因为分相产生的折射率差异会散射光。图案是否有用，取决于用途：连通孔道有利于物质通过，连续致密层有利于阻隔，而规则纳米区域还可以充当后续加工的空间模板。理解图案，首先要说清哪一种物理量在空间中发生了变化。

用体积分数描述二元混合物时，把一个小区域内组分A所占体积除以该区域总体积，便得到零到一之间的数。处处相同称为均匀；有些地方略高、有些略低就是浓度起伏。这个小区域应含有足够多的分子，才有平滑的平均浓度，又要足够小，才能分辨我们关心的结构。另一类图案是膜厚变化：各处化学组成可以相同，材料却从薄处流向厚处。因此显微照片中的深浅相似，并不意味着背后的动力学相同。

图案可以由外部刻出的沟槽规定，也可以从原来近乎均匀的状态自行形成。后一种情形仍然需要起始扰动，热运动、微小厚度差或边界差异都能提供种子。关键问题是这些扰动会消失还是长大。把平放在碗底的小球轻推一下，它会回到低处；把小球放在碗沿的局部最高处，微小偏移就会增大。材料中的稳定性有相近含义，但浓度不能像小球一样在原地凭空增加，富集必须伴随邻近区域的贫化。守恒约束会深刻改变被选中的尺度。

尺度选择还包含三个不同问题。最初哪种波长长得最快，决定早期容易看到的间距；随后区域合并、界面移动，间距可能继续增大；当链连接、表面、弹性或外部驱动提供额外竞争时，才可能形成长期保持的有限尺度。把第一张清晰照片中的间距直接叫作平衡周期，会跳过后面两步。对加工而言，最终保存的尺度也可能来自降温造成的运动减慢，因此需要把材料运动的时间和停止运动的时间一起考虑。

本章先沿着二元聚合物混合物这一条主线，把自由能、物质守恒和空间起伏连起来，再比较嵌段共聚物和反应扩散。这样既能解释为什么某些细小波动会变大，也能看出相似的条纹或斑点可能来自不同机制。每个模型中的“空间”都是实际样品的位置，波长可以由显微成像或散射测量获得；公式的任务是把可测的间距、变化速率和材料参数联系起来。

自由能曲线为何决定起伏的命运

在给定温度下，混合物的自由能综合了分子接触的能量代价和可能排列的数量。先设想若干大小相同的小盒子，每个盒子内部都均匀，用一条曲线表示不同体积分数对应的单位体积自由能。曲线的高度告诉我们相应状态的代价，斜率告诉我们组成稍变时自由能怎样改变，曲率则告诉我们斜率是逐渐增加还是逐渐减少。导数只是把“改变量除以很小的输入变化量”推到局部极限；二阶导数就是对斜率再做一次这种比较。

取两个原本组成都相同的小盒子，把少量A从一个移到另一个，使它们的组成分别增加和减少同样多。总量保持不变，两个自由能变化中的一阶项彼此抵消，主要剩下由曲率控制的二阶项。曲率为正，微小分离使总自由能升高，均匀状态抵抗这种变化；曲率为负，两盒的总自由能反而下降，起伏有继续扩大的热力学趋势。这就是自旋分解区的局部判据。这里的“自旋”是历史术语的一部分，与电子自旋的翻转没有关系。

正曲率也可能出现在最终更适合分成两相的组成范围内。此时微小起伏会衰减，但一个足够大的新相区域可以越过形成界面的代价而继续长大，这叫成核。它与负曲率区内微小波动直接增长的路径不同。曲率测试回答局部稳定性，完整自由能曲线的共同切线回答哪些组成能平衡共存。即使某个均匀状态对小扰动稳定，也还要比较远处其他组成及其组合，才能判断它是不是全局最低自由能状态。

相邻盒子之间的组成变化还需要付出界面代价。若相同的组成差跨越很短距离，空间梯度就大，分子周围环境改变得急。Cahn与Hilliard在1958年的非均匀体系自由能研究中系统采用了梯度项，使界面宽度由能量竞争决定。下面用体积分数和单位体积自由能写出这一思想。积分表示把每个微小体积的贡献加起来，梯度的平方保证改变方向不会把能量代价变成负数。

让物质沿降低自由能的方向迁移

只有自由能还不能告诉我们图案出现得多快。必须再描述物质怎样移动。设想在两个邻近位置交换很少的组分，同时保持总体积。自由能对这种局部组成变化的敏感程度，构成推动交换的势。下面用μ表示每单位参考体积的组成共轭势，其单位为焦耳每立方米。它与常用的每摩尔化学势在归一化方式上不同；比较或代入实验参数时必须保持同一约定。局部项给出自由能曲线的斜率，梯度项则让附近的浓度形状参与决定迁移方向。

物质通量描述单位时间穿过单位面积的组分体积，单位为米每秒。把它取为势梯度的负方向，并乘以正的迁移率，就得到线性耗散关系。再考虑一个小盒子的收支：流进的比流出的多，盒中浓度就增加；流出更多则减少。将这个守恒关系和势的表达式合在一起，便得到常称为Cahn–Hilliard方程的浓度演化形式。这个方程可以产生从低浓度流向高浓度的情形，因为决定方向的是势的梯度，浓度梯度本身不是完整的驱动力。

最先长大的波长怎样选出

把一条缓慢变化的浓度曲线拆成许多波，是研究早期图案的方便方法。一个余弦波有规律地出现富集峰和贫化谷，峰谷平均后为零，所以加在原均匀组成上并不改变总量。波长是相邻峰之间的距离；波数则表示单位距离内相位改变得多快。走过一个完整波长，相位增加一整圈，也就是2π弧度。于是波数等于2π除以波长。大波数表示细密的起伏，小波数表示宽缓的起伏。

在起伏幅度很小时，可以把局部自由能曲线在原组成附近展开，只保留对幅度一次的动力学贡献。不同波暂时独立增长或衰减，幅度随时间乘以指数因子。指数的增长率为正，波就放大；为负，波就衰减。把一个余弦波代入浓度演化方程时，每做两次空间求导便产生一个负的波数平方。由此得到下面的增长率，而不必先求解整片复杂图案。

连续模型给出的最快波数，不一定恰好装得进有限样品。周期区域只能容纳满足整数条件的波，真正最快的允许模式要逐个比较增长率。边界固定浓度或偏好某种组分时，允许模式又会变化。这个区别解释了为什么小样品中可观察的间距会跳变，而连续公式预测的最优波长平滑变化。随着幅度变大，局部曲率不再能用初始值代替，各个波也开始耦合；此时应转向完整非线性演化，而不是继续把指数增长外推到不可能的负浓度或超过一的体积分数。

最快增长也不总等于最先看见。若某个模式最初受到表面缺陷强烈激发，即使它的增长率略低，也可能先达到显微镜能分辨的幅度。测量多个时刻，分别比较各模式信号的增幅，能够把初始幅度与增长率区分开。随机热起伏通常同时包含许多尺度；外加条纹模板则可以偏重某个尺度。外部模板因此既能影响图案方向，也能影响早期竞争的起点，却不必改变材料本身的自由能曲率。分析时需要同时保留初始状态和随时间变化的记录。

早期条纹为何会变粗，也为何能够停下

浓度起伏长大以后，富集区和贫化区逐渐接近各自的相组成，中间形成较窄的过渡层。此时继续降低自由能的一条途径，是减少两相之间的总界面面积。小区域可以消失，大区域可以长大，邻近区域也可以通过接触而合并。显微图上的典型尺寸于是随时间增加，这称为粗化。它不需要两种组分重新混合，恰恰可能发生在局部两相组成已经相当明确的时候。区域内部的组成与区域之间的距离，是不同的观测量。

在稀疏液滴中，较小液滴的曲率更大，界面作用能够抬高其组分交换势，物质经连续相转移到较大液滴，这是一种熟化途径。若液滴随流动相遇并融合，则是另一种途径。连通的双连续结构还可以通过界面驱动的流动改变形状。这些机制涉及不同的输运距离、阻力和几何形态，不能把某一种理想模型的时间幂律套在所有聚合物分相图像上。识别粗化机制，需要同时观察结构变化与材料的运动条件。

高分子链的运动慢，使“观察不到继续变化”尤其值得仔细解释。降温后富集相可能玻璃化，缠结网络或结晶区域也可能限制重排。它们把当前结构保留下来，却不一定使该结构成为自由能最低的周期。稍微升温后若结构重新长大，便能发现先前停止主要来自动力学。反过来，若同一种材料经过不同初始图案都趋向相近周期，并在扰动后恢复，则更支持有限尺度由热力学竞争维持。实验时间有限，因此应记录整个温度与等待时间历史。

嵌段共聚物提供了一种明确的有限尺度机制。A段与B段由共价键连在同一分子上，局部不相容驱使它们分开，连接又使无限远的宏观分离需要过度拉伸链。对于一种简化的层状结构，把周期增大，可以减少每条链分摊的界面代价，却增加链伸展代价。下面把这两项分别写成周期倒数和周期平方；系数包含组分、界面张力和链统计的影响。这是理解竞争的尺度模型，完整相图还要比较球、柱、层等不同几何结构。

能量最低的周期来自两项斜率相互抵消，而不是任意指定一个好看的间距。界面代价越大，系统更倾向于增大周期；伸展代价越大，系统更倾向于减小周期。这个平衡与普通共混物早期最快增长波长的来源不同，也与玻璃化冻结时偶然留下的尺度不同。加工中三种情形还可能接续出现：先形成某个早期尺度，再向较稳定尺度调整，最后因运动停止而保留未完全松弛的缺陷和间距。

周期相近的两种结构，还可能有完全不同的连通性。孤立液滴周围的连续相可以贯通样品，而双连续结构允许两相分别形成跨越样品的路径。若目标是让一种物质沿富集相输运，孤立液滴与连续通道的差别就很关键。组成比例改变时，界面面积、曲率和连通方式往往同时变化，因此不能只追求某个平均孔径。可以把间距测量与三维连通性或渗透实验配合起来，使所选结构尺度对应到实际的传质功能。

扩散为什么也能参与制造图案

扩散常被理解为消除差异：一滴染料逐渐散开，浓度峰变平。对于单个稳定的浓度场，这个理解很有用。但若两种物质会相互影响生成和消耗，扩散还会改变它们在不同位置的反馈关系。Turing在1952年研究化学形态形成时，提出一个重要可能：均匀反应状态本来能够抵抗空间一致的微小扰动，加入不同速率的扩散后，却可能对某些空间波长失稳。这是一种由反应与输运共同造成的稳定性改变。

可以先想象一种局部变化会促进自己，同时促进一种抑制作用；抑制作用又反过来压低原来的变化。如果抑制影响传播得更远，局部峰值附近和远处受到的竞争不同，就可能留下有限间距。这个图像有助于理解局部放大和远程抑制，但实际反应网络并不总能简单分成一种促进剂和一种抑制剂。判断具体体系是否具有这种失稳，仍要使用反应速率对浓度的响应和各物质的扩散系数。

为了把“扩散改变反馈”算清楚，用u和v表示两种浓度相对均匀稳态的小偏差，先各自除以参考浓度，成为无量纲数。偏差可以为负，实际浓度仍然为正。把反应速率在稳态附近保留一次项，四个系数分别描述两种偏差如何改变各自与彼此的变化率。加上普通扩散，就得到下面的一组方程。它们描述早期扰动，不承担完整化学反应的饱和和物质供应细节。

算一个例子a=1,b=−2,c=2,d=−3 s⁻¹时，均匀增长率为−1 s⁻¹的重根。Du=1,Dv=20 μm² s⁻¹、q=0.5 μm⁻¹时，自身系数为0.75与−8 s⁻¹；增长率σ满足σ²+(7.25 s⁻¹)σ−2 s⁻²=0，正根为0.2661 s⁻¹。

取a=1、b=−2、c=2、d=−3，单位均为每秒。空间完全均匀时，两种偏差的耦合增长率都为−1每秒，因此小扰动最终衰减。再取扩散系数分别为1和20平方微米每秒。对波数0.5每微米的空间波，扩散把两个自身响应系数分别降低到0.75和−8每秒，而交叉作用不变。代入共同指数增长的形式，可得到增长率满足的二次方程，其中一个解约为正0.266每秒。原来稳定的均匀状态，因空间输运改变反馈比例而出现增长模式。

这个例子中每个扩散项本身仍然抹平相应物质的浓度起伏，增长来自完整耦合系统，而不是扩散单独向浓处搬运物质。若两个扩散系数相同，对每一种空间波只是把全部反应增长率共同向负方向平移，这种两变量线性机制便无法由扩散产生失稳。持续的化学图案还需要相应的反应条件和物质或能量供应。普通被动聚合物共混物的分相可以在自由能下降过程中发生，不能仅凭斑点相似就把它称为Turing图案。

边界、缺陷与加工历史怎样选择最后的样子

早期线性计算告诉我们哪些波长会竞争，却不能单独决定完整的最终图案。波幅长大后，同一位置的浓度不能超过物理允许范围，各个波也不再互不影响。一个模式的增长会改变其他模式所处的局部环境；条纹的方向、连接方式和缺陷需要一起调整。因此从一个增长率最高的波数走到一张真实二维或三维图案，中间还隔着非线性竞争和几何组织。最先增长的模式可以留下影响，也可能在后续演化中被替换。

用一个选定模式的幅度作例子，可以给线性增长加上一个随幅度立方增加的抑制项。幅度很小时，线性项占优；幅度较大时，抑制项赶上来，产生有限的稳态幅度。三次项之所以保留正负对称，是因为把整个波的峰谷交换，相当于改变相位，并不应无故改变增长规律。这样的幅度方程可以解释饱和的基本逻辑，但它只描述已选定模式，不会自动选出所有可能的空间波长或完成缺陷消除。

边界对图案的作用很具体。若壁面更喜欢A组分，靠壁区域先富集A，形成与壁面平行的层；若两侧壁偏好相反，薄膜内要同时满足两个要求，层数和缺陷就可能改变。样品宽度若刚好容纳整数个自然周期，排列较容易连续；若差半个周期，就要通过伸缩、转向或缺陷来协调。边界不是一条无关紧要的图框，而是自由能和允许结构的一部分，尤其在薄膜、孔道和小尺寸器件中如此。

缺陷是有序排列无法处处衔接的位置，例如一条层纹在内部终止，或不同取向的条纹区域相遇。消除缺陷需要物质搬运和链重排，可能比局部相分离慢得多。一张有许多缺陷的图像，既可能表示还在松弛，也可能表示边界持续施加不相容条件。沿时间观察缺陷移动、合并和停留的位置，可以把这些情形区分开。对于需要贯通通道的材料，少量缺陷的连接作用有时比平均周期更影响输运。

加工速率也在选择路径。快速降温可让很多微小起伏几乎同时进入不稳定区；慢速改变条件则给早先形成的区域更多调整时间。溶剂挥发还会沿厚度产生浓度差和温度差，表层先变黏，内部仍在流动，最终结构因而带有深度方向的差别。若希望获得均匀孔径或整齐层纹，需要把外部条件变化的速度与链扩散、界面移动和溶剂迁移的速度一起设计。仅报一个最终温度，通常不足以复现这种加工过程。

怎样从图像和时间序列判断机制

面对一幅材料图像，先确定颜色或亮度对应什么。电子显微图可能反映组成、染色或表面形貌，偏振图可能反映取向与厚度，透射光中的浑浊则来自折射率起伏的散射。若把所有对比都直接当作浓度，就会混淆不同机制。用独立测量确认组成、厚度或取向之后，再谈区域大小、连接性和规则程度，图像中的几何描述才有明确的物理对象。对于多孔材料，还要区分二维截面中的相邻和三维空间中的真正连通。

确定特征尺度时，可以在图上量相邻峰的间距，也可以把整个图像与不同方向、不同波长的波形比较。某种波形与图像最相似，就会在对应波数附近出现较强信号；散射实验也能给出与空间相关相联系的波数峰。把峰的位置换成波长要使用2π除以波数，而不是直接取倒数，因为波数按弧度每长度定义。宽峰表示一组尺度或较短的空间相关范围，尖峰表示较集中的周期信息；峰形还受到取向分布、仪器分辨率和有限视野影响。

使用条件峰确实对应所讨论的空间相关尺度；复杂形状因子、多个结构层级和取向平均需要结合完整谱分析。

时间序列尤其有辨别力。如果早期不同波数的信号按各自固定速率增加，可与线性增长谱比较；如果峰逐渐向小波数移动，说明典型尺寸在增大；如果峰位置保持不变但峰强或宽度仍变，可能是组成对比增强、取向改善或缺陷减少。散射强度通常与小幅浓度波的幅度平方相关，所以从强度的指数增长率反推幅度增长率时要除以二。这一步必须先确认处于相应散射近似和线性阶段，不能把仪器直接读出的斜率随意代入幅度方程。

薄膜退润湿提供了一个观察结构接续变化的例子。Reiter在1992年的聚苯乙烯薄膜研究中描述了孔洞形成、孔缘增长并相遇，以及边缘结构进一步变成液滴的过程。把这些阶段画在同一条时间线上，会发现“孔洞间距”“蜂窝状结构尺寸”和“液滴间距”并非同一个固定尺度。膜厚是这里的守恒场之一，基底作用与表面张力共同影响演化。观察孔洞从哪里出现、是否与缺陷相关，并比较早期空间谱，才能进一步区分成核和连续失稳等起始路径。

最后，把模型预测转换成能改变的实验条件。测试梯度代价或相容性对早期尺度的影响，需要在相近迁移条件下改变淬冷深度；测试动力学冻结，需要安排等待、升温和再等待；测试边界选择，需要改变膜厚或表面偏好；测试反应扩散，需要测量反应反馈与不同物质的输运。每种实验都把一个具体因果关系与可观察结果连接起来。材料图案由此成为可设计、可测量的结构：它的形成速率、间距、连通性和保存方式共同决定最终用途。

实际测量还要检查观察窗口。若一幅图只包含两个周期，峰位置容易受裁切与边缘影响；若一个周期只占两三个像素，细节又会被分辨率抹去。扩大视野和提高分辨率分别解决不同问题，最好在重叠尺度上比较多种放大倍数。对同一样品在不同位置取图，还能判断表面缺陷附近的局部图案是否代表整体。这样的尺度检查不改变物理模型，却决定实验能否可靠区分两个相近的候选波长。
