先决定要把什么混到什么程度

一袋玻璃纤维增强尼龙颗粒，看起来只是许多形状相近的小圆柱；一片导热聚丙烯外壳，看起来也像普通塑料。然而，纤维有没有被树脂包住、导热颗粒有没有形成合适的接触、每一小份材料的组成是否一致，都在成型之前的混合过程中受到影响。混合不是把配方上的几种原料倒进机器就结束。它要把规定的组成变成能够稳定加工的材料，同时保留需要的分子长度、纤维长度和相结构。相同配方经过不同的加料顺序、温度和剪切历史，可能得到明显不同的产品。

可以先想象做一碗带可可粉的面糊。把深色面糊从一边搬到另一边，会减小不同位置之间的颜色差异；把仍然存在的粉团压碎，则解决另一个问题。前者对应分布混合，关注一种组分在空间中是否分布均匀；后者对应分散混合，关注团聚体或液滴是否被细化。把许多完整粉团均匀分布，能够做好第一件事而没有做好第二件事。反过来，局部粉团已经细化，材料却仍有大范围的浓度条带，也需要继续分布混合。这两个目标必须分别观察。

聚合物熔体中的“搅拌”通常不像水杯里的湍流。长链使熔体黏稠，许多加工流动主要依靠层层拉伸、折叠、分流和重新汇合来增加不同组分接触的面积。对于两种可以在分子尺度混合的聚合物，界面变薄有助于分子穿越较短距离；对于不相容的树脂，界面仍然存在，最终形成的是细小分散相或相互贯通的结构。图中的颜色表示组分位置，不暗示两种不同聚合物已经变成一种化学物质。

分散为什么需要足够的作用强度？团聚体内部有接触和吸引，液滴则有使界面面积缩小的界面张力。外部流动必须产生足以拉伸或破坏它们的应力，才能使尺寸减小；作用之后，液滴还可能碰撞并重新并合。因此，增加转速有时能细化液滴，有时又因温度上升、基体黏度下降而减弱应力。剪切与拉伸流动也有不同效率。选择混合元件时，需要同时考虑材料抵抗破碎的方式、流场的变形方式，以及碎开之后怎样稳定新界面。

“均匀”还需要一个观察尺度。一个装有黑白颗粒的料袋，可以在每千克取样时组成接近，却在每克取样时波动很大；制成薄膜后，几百微米的颜料团可能已经足以形成可见缺陷。评价方法应与使用要求相接：颜色测量、显微图像、灰分含量、导电性或力学性能各自回答不同问题。把几个取样位置的浓度放在一起计算离散程度，能够给分布混合一个定量描述，但取样数量、位置和样品大小必须同时固定。

配方进入机器之前：预混、计量与加料

树脂通常提供连续的基体，填料、增韧剂、颜料和稳定剂改变某些性能。商品牌号还可能通过聚合阶段调整分子量、共聚组成或粒子结构。因此，选择基础树脂与后续配混是相接的两个环节，不能把所有牌号差别都解释成“加入的助剂不同”。设计配混时，首先列清组分的质量比例、原料形态、允许含水量与受热条件，再选择怎样把它们稳定送到同一条加工线上。

预混常在粉体或颗粒状态下进行。低速滚动适合温和地交换颗粒位置，高速混合机则利用叶片推动、碰撞和摩擦，使粉料与少量助剂更充分接触。摩擦本身会发热；某些配方需要热混后再冷却，防止后续储存时结块。预混均匀的物料在运输、振动和落料时仍可能再次分离：小颗粒会穿过大颗粒间隙，密度不同的组分也可能出现偏聚。因此，料桶中的均匀状态必须延续到喂料口，不能只在混合机出料时取一份样品。

连续生产常用失重式喂料器：设备持续称量料斗和物料，依据单位时间减少的质量调整送出速度。它控制的是质量流量，单位可用千克每小时；定容喂料器主要控制螺杆或转子的转速，当粉体松装密度变化时，相同体积未必对应相同质量。失重计量也有补料、架桥和称重扰动问题。对含量很低的助剂，可以先制成浓缩母粒，再与树脂稀释，这样既有利于计量，也有利于初步分散，但母粒中的载体同样进入最终配方。

吸湿性聚合物进入高温加工前，需要把水分控制到适合该材料的水平。水不仅可能变成气泡，还会使聚酯、聚酰胺等材料在高温下发生水解断链。干燥时间、温度、干燥空气状态和物料厚度共同影响结果；完成干燥后长时间暴露在潮湿空气中，会重新吸水。另一方面，纤维、易扬尘粉体和液体助剂可能适合从不同位置加入，让加料方式服务于润湿、分散和结构保护，而不是坚持所有东西都从主料斗同时进入。

间歇混合每次处理一批，便于按步骤加料并调整终点；连续混合则让原料不断进入、产品不断离开，适合稳定的大流量生产。两者的质量都依赖控制。间歇设备若装料量和排料温度重复，批间一致性可以很好；连续设备若喂料脉动或启动尚未稳定，也会出现组成偏差。选择时还要考虑换色清洗、配方切换、产量和停留时间，而不是把“间歇”直接等同于不稳定，把“连续”直接等同于节能和均匀。

从辊筒到密炼室：材料经历了多少作用

开炼机用两个相向转动的辊筒带动物料通过辊隙。表面速度不同、间隙较小的区域可以产生明显变形，物料再经过翻动和重新进入辊隙，逐步交换位置。辊筒可以加热或冷却，具体温度由橡胶或塑料的性质决定。橡胶混炼也常因机械作用而升温，不能把“橡胶在开炼机上加工”理解为全过程保持室温。辊隙是实际设备中的危险夹点，生产操作由设备防护与规定操作程序组织；理解流动机制并不需要用手接近辊隙。

密炼机把转子放在相对封闭的混合室内，上方压料装置帮助物料进入有效工作区。转子与室壁之间的窄隙使物料受到较强变形，较宽空间则让它循环、折叠和重新分配。不同转子翼形、转速比、填充程度与加料顺序会改变这些经历。装得过少，物料未必充分进入作用区；装得过满，流动、排气和温度控制也会受到影响。有效混合来自材料反复经过不同流动区域，而不是某一点的剪切越强越好。

几个相近词需要区分。橡胶的混炼是把配合剂混入并分散在橡胶中；塑炼通常指通过加工降低橡胶的黏度、改善后续加工性，其中可能包含链断裂。塑料的塑化则是让固体原料受热和机械作用，成为适于流动与成型的均匀软化物或熔体；即使没有添加任何助剂，纯树脂也需要塑化。半结晶树脂的塑化涉及晶体熔化，无定形树脂则主要经历随温度和时间尺度变化的软化。

实验室转矩流变仪常配一个小型混合室。转矩是使转子转动需要的“拧劲”，单位为牛顿米。记录转矩和温度随时间的变化，可以看见装料、软化、融合和后续变化，但转矩还受装料量、转子形状、转速及壁面作用影响。它不是拿来就能当作材料黏度的独立常数。比较配方时，保持测量条件一致并与参照配方对比，才容易把曲线差别连接到材料行为。

对某些PVC干混料，最初的高峰主要来自装料阻力，随后转矩下降；颗粒在热与变形作用下融合，可能出现另一个峰。继续加工后，温度和流动阻力进入相对平稳阶段。更晚的转矩上升有时与降解后的交联等变化有关，链断裂占主导的体系却可能出现下降。PVC稳定剂涉及抑制脱氯化氢及相关降解反应，不能把整个过程说成自由氯离子简单积累。曲线特征应与颜色、实际料温和取样结构一起读，融合峰也不是所有树脂共有的熔点标志。

一根螺杆怎样输送固体并把它熔化

单螺杆挤出机由料斗、机筒、旋转螺杆、加热冷却系统以及出口机头等部分协同工作。螺棱像沿圆柱绕行的凸起墙壁，螺槽是相邻螺棱之间容纳物料的空间。常见螺杆从较深的加料段逐渐过渡到较浅的计量段，中间承担压实和塑化。这些是几何分段；固体输送、熔融和熔体输送则是物料状态的分段，实际边界会随树脂、转速和温度移动，并不永远落在固定螺杆位置。

只把螺杆想成旋转的铲子，会漏掉机筒的作用。假如紧贴螺杆的物料随它整体转动，却没有相对运动，它就不容易沿螺槽前进。物料与机筒、螺杆之间不同的摩擦，连同螺棱的约束，使固体床得到轴向输送。1956年Darnell与Mol把压实颗粒近似为固体床，用受力平衡研究这一问题；后来的模型逐步加入温度、压实等影响。这个思路让人看到：喂料能力取决于颗粒和金属表面的接触状态，温度升高导致的黏附或润滑变化也会改变输送。

松散颗粒首先要被连续送入并排出一部分间隙空气。粉体架桥会让料斗下方看似有料，螺杆却间歇缺料；颗粒几何、松装密度和回用料形态也会影响供料。某些单螺杆设计采用沟槽机筒增强固体输送，但沟槽、进料段冷却和后续塑化能力必须配合。提高进料能力而熔融能力没有同步增加，可能把未熔颗粒一直送到下游。

机筒里的材料不透明，早期研究者必须想办法看见内部。Maddock在1959年的研究中采用停止挤出、冷却并取出螺杆后观察物料的办法，识别固体床、薄熔膜和熔池。Tadmor在1966年建立的经典熔融模型，把热机筒传入的热量与薄熔膜中黏性变形产生的热量结合起来，计算固体床如何逐渐变窄。科学上的进步在于把“这段应该熔化”变成能够观察和计算的沿程变化。

在这一经典图景中，靠近热机筒的表面先形成薄熔膜，螺杆和机筒的相对运动使熔体被扫向一侧，形成越来越大的熔池，剩余固体床逐渐缩小。图画的是一种稳定固体床的熔融机制；缺料喂入、固体床破碎、不同螺槽设计或双螺杆中的熔融，可以出现不同路径。模型的价值是把热传递、机械生热和物料迁移连起来，再依据实际状态选择适合的描述。

使用条件示意能量账，假定最终晶体完全熔化；不含散热、化学反应或设备升温，热源可同时来自机筒与机械耗散。

半结晶树脂还需要吸收使晶体失去有序排列的熔融热。晶体含量较高时，在相同升温幅度之外会增加这部分需求；无定形树脂没有同样的晶体熔融项，但其比热和黏度仍随温度变化。颗粒外部已经变软，也不保证中心已经达到相同温度。聚合物传热相对慢，颗粒大小、固体床厚度和接触状态都会影响内部升温速度。由总能量算出“理论上足够”，还应继续问热量是否在有限停留时间内送到了需要熔化的位置。

这份能量账还解释了为什么机筒设定温度不是最终熔体温度。电加热器供热，机械作用也把功转成热；在高负荷运行时，机筒甚至需要冷却以带走多余热量。提高螺杆转速可能提高产量，也可能提高局部温升并缩短熔融时间。判断是否塑化充分，需要结合熔体温度、未熔物检查、压力稳定性和产品表现，不能只看控制面板上的加热温度是否达到目标。

熔体既被向前拖，也受到出口阻力

材料完全熔化之后，输送机制变成黏性流动。为了先看清主要因素，可以把一小段螺槽展开成宽而浅的直通道，在随螺杆移动的观察方式中，让上壁相对下壁运动。靠近移动壁的熔体被拖向前方，这部分称为拖曳流；若出口压力更高，压力差又推动熔体向反方向流动，构成压力回流。净流量是两者竞争的结果。螺棱顶端的间隙还会发生漏流，精细计算时要另外计入。

这个模型中的壁面速度指沿展开通道方向的分量，不是直接把螺杆每分钟转数写进去。实际速度要由转速、直径与螺旋角换算。同样，通道长度沿螺槽计算，与机筒的轴向长度不同。先把这些几何关系分开，能避免一个常见误解：螺杆每转一圈，就必然把一段固定体积的熔体无损送出去。对常见单螺杆熔体输送，出口阻力和黏度会改变实际输出。

交互把通道几何和黏度固定，只改变壁面速度与外加压力差。零压力差时看到的是拖曳输送上限；压力升高，净流量下降。若计算到零，表示该简化通道的拖曳与回流恰好抵消；负值表示外加压力足以使净流动反向。这里压力由你独立指定。连接真实口模后，压力与流量要同时满足口模的阻力关系，机器工作点位于两者相容的位置，并非能随意选择任意一组压力与流量。

真实聚合物熔体常剪切变稀，温度也不均匀，通道侧壁与螺旋曲率进一步影响速度场。简化关系先解释方向和几何敏感性，设备设计再采用相应的非牛顿流动和传热描述。测量上的压力异常也可能源于过滤网堵塞、出口收缩、未熔物或温度变化。一个压力传感器读到的是所在位置的状态，多个位置的测量更有助于定位阻力在哪里增加。

两根螺杆怎样分工：输送、混合与排气

双螺杆不只是把单螺杆数量加倍。两根螺杆可以同向或反向转动，可以相互啮合或保持分离，外形也可以是平行或锥形。啮合是指一根螺杆的螺棱进入另一根的槽区附近，实际仍留有工作间隙。不同组合决定物料能否在两根螺杆之间交换、局部空间是否近似封闭、怎样建立压力，以及哪些位置承担较强混合作用。名称相近的设备，物料路径可能很不相同。

紧密啮合的同向双螺杆常用于配混。物料能在两根螺杆之间转移，螺杆表面相互扫过，有助于减少长期滞留。所谓自清扫并不意味着设备永远没有残留，也不等于两根金属螺杆直接接触。间隙、元件连接处、机头结构及实际黏附都会影响换料清洁程度。异向啮合螺杆的一些几何结构则形成近似封闭的C形小室，具有较强的正位移输送特征；间隙漏流仍会影响产量。这类设备在PVC管材和型材加工中有重要用途。

同向设备的分段螺杆可组合输送元件、捏合块和不同混合元件。正向输送元件帮助物料前进；捏合盘的错列角、盘宽和组合方式改变分流、回混、局部填充和变形。反向或阻力较大的元件可在上游形成充满区，增加停留和混合，但也增加压力消耗和温升。捏合块越多并不自动意味着产品越好，长纤维可能被折断，敏感聚合物也可能因受热过久而降解。

不同混合元件也会把同样的总作用分配成不同空间历程。齿形或分流元件通过把物料分成多股并重新组合，增加组分之间的接触界面，适合改善分布；窄隙和捏合区域则可以提供较强局部应力。静态混合器没有旋转部件，利用固定流道分割、旋转并重组流束，同样能够混合，代价是消耗压力。因而“没有运动零件”不等于没有混合作用，“转子运动剧烈”也不等于所有物料都经过了相同作用。

计量喂入的双螺杆常采用欠饱和喂料：输送段只部分充满，而需要建立压力或强烈混合的区域可以局部充满。这使喂料量和螺杆转速成为两个可以配合调整的变量。增大转速而不增加进料量，会改变每转承载的物料量、充满程度和作用次数，效果不能只用“搅得更快”描述。连续设备也不是所有段都保持高压，排气口恰恰需要适合释放气体的状态。

脱挥利用熔体表面更新、较低气相压力和物料内部向表面的迁移，把水分、残余单体或溶剂带走。真空口前后需要适当的压力与熔体密封安排，避免空气大量吸入或熔体从排气口冒出；排气区也要留出气体空间。把已经严重水解的树脂随后抽干，不能重新接回被切断的长链，因此预干燥与脱挥解决的是相接而不相同的问题。侧喂料则让纤维或粉体在树脂已经软化后进入，便于润湿并减少不必要的机械历程。

挤出机还可以兼作连续反应器，例如反应增容、接枝或热塑性硫化胶的动态硫化。此时流动既改变混合，化学反应又改变黏度和相结构，必须协调反应速度、混合速度与停留时间。不同反应需要自己的供料、热量和挥发物控制，不能因为原料经过双螺杆就认定已经发生接枝。离开机器之后还要用合适的化学或结构测量确认所设计的变化。

材料不是同时进、同时出：停留时间与放大

连续挤出时，同一时刻加入的少量示踪物不会在某个瞬间整齐离开。部分物料走较快的路径，部分经历回混或较慢的壁面附近流动，于是出口出现一段浓度随时间变化的曲线。它描述停留时间分布。平均停留时间告诉我们典型经历了多久，而较长的尾部提醒我们有少部分材料停留更久；对热敏树脂，尾部往往与变色、凝胶或降解残留有关。

使用条件窄脉冲示踪、代表基体运动并回收到足够长的尾部；用浓度代替质量权重时需要计入取样时段与相应流量。

还要把时间尺度与生产稳定性联系起来。如果某种助剂的喂入突然停止，出口组成不会立即完整响应；机器内部已有的物料会继续排出，变化被输送和回混展开成一段过渡。停留时间测量能帮助安排换料后的取样时间，并估计需要隔离多长一段过渡产品。为了使试验可比较，示踪剂加入量应足够检出又不显著改变黏度，取样应覆盖长尾，检测器自身的延迟也要与物料停留区分。

在恒定流量、窄脉冲加入且示踪物能代表基体运动的条件下，出口各时间区间回收的示踪物质量可作为权重。早、中、晚三个区间分别在20、40、80秒排出20%、60%、20%的示踪物，平均为44秒。把这个结果说成每一份物料都停留44秒，会抹去真正有用的差异。若流量变化、示踪物黏附在壁面或与某个相优先结合，就需要相应调整解释，不能只把曲线归一化后直接比较。

放大设备也不能只按直径比例放大配方时间。较大螺杆的容积、表面积和传热距离以不同方式变化，单位物料接触冷却壁面的机会会改变。保持相同转速时，较大直径的表面速度更高；保持相同比机械能，也不保证每份物料经历相同最大应力或停留时间。合理的放大把产量、扭矩负荷、熔体温度、停留时间分布和分散质量一起比较，并根据材料最敏感的变化选择控制重点。

仪器信号需要与产品样品连起来。进料量波动时，压力、转矩和组成可能一起变化；温度逐渐上升时，即使配方不变，转矩也可能下降。记录实际熔体温度、各路喂料、转速、压力和取样时间，才能把一个缺陷追溯到对应物料经历。启动、配方切换和稳定运行应分别评价，尤其要避免把机器仍在置换旧料时的样品误当作新配方的稳定性能。

提高产量通常要找当前真正的限制：喂料能力、熔融能力、扭矩、温度、排气或机头压力都可能成为瓶颈。增加转速在某些条件下能增加产出，在另一些条件下只是使物料更热或更短时间离开。确定限制后再改变螺杆组合、加料位置或温度程序，能够让调整有明确对象，也更容易通过连续取样判断改动是否产生了预期作用。

把一条加工路线设计成可检验的材料方案

制定路线时，先为每种原料建立与加工有关的基本描述：树脂的流动特征和含水状态，粉体的粒径与团聚情况，纤维的初始长度及表面处理。这样，后续出现性能变化时，可以区分是原料批次已经不同，还是加工改变了结构。进料描述与成品检测使用相互对应的指标，也让不同试验批次之间的比较更清楚。

以聚苯乙烯增韧为例，把聚丁二烯简单熔混进去，首先得到的是两相材料。要改善冲击性能，需要橡胶相有合适尺寸、界面联系和体积分数，还要避免聚丁二烯受热氧化。可选相容或接枝结构帮助稳定界面，选择合适的树脂黏度和混合条件控制形态，再检查拉伸、冲击以及显微结构。工业HIPS常通过在橡胶存在下聚合苯乙烯形成特有的接枝和包藏结构，因此熔混PS与PB的路线应按其实际结构评价，不把它自动命名为同一种微观组织。

若目标是导热聚丙烯，关键变成填料润湿、接触网络和成型后的取向。氮化硼、氧化镁与炭黑并不只是互换的“导热粉”：形状、密度、表面性质及电绝缘要求都影响选材。片状填料可能使面内与厚度方向导热不同，炭黑还会明显改变导电性。填料越多，黏度、脆性和密度也可能增加。路线设计应先确定热量沿哪个方向传递，再通过多点取样和对应方向的测量检查是否形成有用结构。

玻璃纤维增强尼龙则需要在分散与保长之间取得合适平衡。先把尼龙干燥、塑化，再在合适下游位置侧喂入带有相容表面处理的纤维，可以减少纤维在整个螺杆长度内反复受力。后续仍需足够混合使树脂润湿纤维束，而不能为了保长留下干束和孔洞。颗粒中的纤维长度分布、界面状态和实际成型后的取向都要检查；只报告投料时纤维很长，尚未说明最终制品如何承担载荷。

这三条路线共用计量、输送、塑化和混合，却有不同的最佳结构。颜料或无机粉团常希望被充分解聚，增韧橡胶要形成有效的相尺寸，增强纤维则希望在充分润湿后保留可传递载荷的长度。由此可以把工艺调整写成具体因果问题：改变哪个区域的作用，使哪一种结构发生怎样的变化，再用哪项测量检查。这样的加工方案把设备参数与材料性能真正接起来。

当颗粒稳定地从切粒机落下时，配混工作并未只留下一个配方编号。材料已经积累了温度、应力、停留和反应的历史，形成下一步成型的起点。合格的均匀熔体意味着组成、温度和结构达到当前用途所需的状态，也意味着需要保留的长链与增强结构得到了保留。理解这一点，就能把挤出机看成一组连续发生、可以测量和设计的物理过程，而不只是一个会把原料挤出来的黑箱。
