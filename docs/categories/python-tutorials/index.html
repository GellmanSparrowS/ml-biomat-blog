Python科学计算

学习科学计算工具和常用编程方法，涵盖环境搭建、数组、表格、拟合、绘图与网络分析。

7 篇

NetworkX 基础：用 Python 理解、构建与分析网络

用 NetworkX 表达节点、连边、方向与权重，再计算度数、中心性、聚类和最短路径。结合邻接矩阵、经典网络模型与社区发现，说明不同指标回答什么问题，以及如何把结构数据转成可分析的图。

NumPy完全入门：实验室数据处理必备

把实验测量整理为数组，逐步使用切片、布尔筛选、广播运算和统计聚合。通过应变与应力数据、逐列中心化及简单拟合示例，理解形状和索引如何影响计算，并将处理结果保存为后续分析可用的数据。

Pandas实验数据处理实战：从原始数据到统计分析

用 DataFrame 整理实验记录，处理缺失值、列名与异常数据，再按实验条件汇总重复测量。结合样品编号合并、数据透视和结果导出，保留样品与测量之间的对应关系，方便继续绘图和建模。

Python 科学计算环境完全搭建指南：从零到生产力

从独立环境、工具包安装到 JupyterLab 内核与 VS Code 解释器，逐步建立可复用的科研计算环境。结合版本冲突、安装路径与环境导出示例，说明常见故障该从哪里排查。

Python科研工具箱完全指南：材料科学与生物研究必备

围绕材料研究中的数据对象，连接 NumPy、SciPy、pandas、绘图、原子结构和图像分析工具。通过力曲线处理、分组统计、显微图像分割与机器学习示例，说明各工具在实际分析中的分工与衔接。

Python科研绘图完全指南：从数据到发表级图表

使用 Matplotlib 与 Seaborn 绘制折线、散点、分布、热图和多幅子图，理解图形选择如何影响读者对数据的判断。结合配色、单位、不确定性、版面尺寸与导出设置，完成可直接用于论文排版的图表。

SciPy曲线拟合完全指南：从线性回归到非线性建模

从线性趋势、应力松弛到压痕模型，演示 SciPy 曲线拟合中的函数定义、初值、单位与参数边界。通过残差、协方差矩阵和置信区间，理解拟合参数的含义，并检查模型与测量数据是否匹配。
