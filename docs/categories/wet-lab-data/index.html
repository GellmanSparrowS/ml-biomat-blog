Python实战AFM力曲线分析：从原始数据到力学性能

从 AFM 偏转信号转换为力，完成基线校正与接触点识别，再对压入数据进行拟合。标定几何、解析 Hertz 曲线与 Python 函数共同说明测量通道如何转换为黏附力和具有明确单位的弹性模量。

SEM图像分析实战：纤维形态的自动化测量

通过预处理、阈值分割、掩膜清理和骨架分析，将纤维显微图像转化为经过标尺校准的测量结果。构造几何解释局部直径和取向提取，Python 示例支持重复执行与批量处理。

从分子到样品：制备、加工与层级结构

沿丝纤维成形过程理解牵伸、水分与结构演变，用公开实验数据比较工艺和结构信息对强度、断裂应变预测的作用。

从实验信号到可用的数据

生物材料力学测试：试样制备、仪器设置与无伪影数据

从试样几何、水合状态、装夹与应变测量出发，建立可重复的生物材料力学测试流程。结合力到应力的换算、直径误差传播和报告要点，明确模量、强度与耗能所对应的测试条件。
