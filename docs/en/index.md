## Research tutorials

### [From Branches to Gels: Fractals, Percolation and Networks](https://ml-biomat.com/tutorials/biomaterials-courses/cp09/en/)

Why can a liquid become a connected load-bearing material? How does a sparse set of conducting fillers span a specimen? Begin with shapes that remain irregular under magnification, then follow connection, mechanical support and solvent uptake to distinguish gel formation from gel-volume transitions.

### [Predicting Fiber Mechanics: Features, Regression and Validation](https://ml-biomat.com/posts/ml-predict-fiber-mechanics/)

Build a small-data regression workflow for fiber mechanics, from specimen features and preprocessing to model comparison. Examine cross-validation, bootstrap variation, and feature importance to connect numerical predictions with material descriptors.

### [Setting Up a Python Scientific Computing Environment](https://ml-biomat.com/posts/python-env-setup/)

Set up isolated Python environments, install the scientific stack, and connect the right interpreter to JupyterLab and VS Code. Learn how to diagnose package conflicts and reproduce a working setup.
